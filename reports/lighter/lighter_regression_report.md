# 回帰 — 222 特徴量を全部入れて標本外でどこまで行くか

[← Lighter の分析索引](README.md)

## 何を測ったか

(1) 各特徴量の**単回帰の傾き**(y[bp] を x の IQR あたりに直した記述統計 —
[特徴量報告](lighter_features_report.md) の表に併記)と、
(2) **リッジ回帰に 222 個を全部入れた多変量の標本外性能**。

## 時間契約(多変量)

- 時間分割: 各銘柄の**前半 70% で学習、後半 30% で評価**(シャッフルしない)
- 標準化(中央値・IQR)は**訓練期間だけ**で推定し、±5 にクリップ
- リッジの λ は**訓練の末尾 20%** を検証にして選ぶ(評価期間は見ない)
- y = 60 秒後リターン[bp]を**訓練期間の sd で割る**(銘柄内標準化 —
  y を揃えないと R² が負に出る事故は Boros 報告⑱で実測済み)
- **y の窓は重ねない**(60 秒間隔で間引く)→ 1 銘柄 2.1〜2.6 万標本
- 帰無対照: X を行方向に巡回シフトして同じ手順

## 判定

1. **実測 > 帰無 が 12 銘柄中 9**。中央値 +0.019 対 +0.004 で、
   方向としては「入っている」。ただし XAU は帰無が実測を上回り、
   SNDK は実測が負 — **銘柄をまたいで頑健とは言えない**
2. **R² は全銘柄で負**。二乗誤差では平均を出すより悪い。
   順位（ρ）は僅かに拾えるが、値の予測はできていない
3. **検証は 1 銘柄 5〜6 日**しかなく、日単位の符号検定は検出力不足。
   「効かない」の証明でもない
4. 面白いのは **MSFT の +0.107** — Lighter で最も薄い銘柄。
   [リードラグ報告](lighter_leadlag_report.md)で Binance 先行が最大(シェア 0.89)
   の銘柄でもあり、**薄い板は自分の過去(の板情報)からも予測されやすい**、
   という一貫した絵になる

## 自己精査

- 損益ではない(費用・執行未計上)
- λ・標準化・y 正規化のどれも評価期間を見ていない(冒頭の設計)
- 帰無が正に出る銘柄がある(+0.035)= この標本サイズでは帰無の揺らぎが
  実測級になり得る、というスケール感の提示でもある
- 係数は `E:/Memory-lighter/ana/reg_coef_*.parquet`。係数の解釈は
  多重共線(相関行列の報告)を踏まえていないので本文では述べない
