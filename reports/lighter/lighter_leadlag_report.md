# ★Lighter × Binance のリードラグ — 12 ペアの徹底測定

[← Lighter の分析索引](README.md)

## 何を測ったか

Lighter の 13 銘柄のうち Binance USD-M 先物に同名 perp がある **12 銘柄**
(H100 は Binance に無い)について、両取引所の BBO mid のリターンで
**どちらが先に動くか**を測った。系列は Lighter ticker(1.16 億行)と
Binance bookTicker(ライブ記録、DRAM だけで 4,700 万行)。
窓は 2026-08-18〜09-05(追加銘柄は 08-22〜)。

対応: DRAM↔DRAMUSDT、MU↔MUUSDT、SNDK↔SNDKUSDT、SKHYNIXUSD↔SKHYNIXUSDT、
SAMSUNGUSD↔SAMSUNGUSDT、AAPL/AMZN/MSFT/NVDA/TSLA/XAG/XAU↔同名 USDT。

## 時間契約と設計

- **時計は 2 通りで全部測る**: server(取引所のイベント時刻)と
  local(このマシンの受信時刻 — 両レコーダが同一マシンなので共通の物差し)
- グリッド Δ=1s(±30 秒の CCF・偏相関)と Δ=0.25s(±3 秒の細部)。
  LOCF、直近更新が 10 秒より古い点は無効
- **単位は 銘柄×日**で推定 → 日をまたいで中央値 → 銘柄横断は表で並べる
- 符号規約: CCF の k>0 は「Binance の r(t) × Lighter の r(t+k)」= **Binance 先行**
- 帰無対照: **日ずらし**(Binance の日 d × Lighter の日 d+1 の同時刻帯)。
  同時性を殺し日周パターンだけ残す
- 層別: 米国現物立会(13:30–20:00 UTC・平日)とそれ以外

## ★時計の診断 — 先に測っておかないと結論が動く

| | 受信 − サーバ時刻(日次中央値の銘柄中央) |
|---|---:|
| Lighter | **−62.3ms** |
| Binance | **−62.5ms** |

**両取引所とも −62ms で一致**した。受信がサーバ打刻より 62ms「早い」ことは
物理的にあり得ないので、これは**このマシンの時計が真の UTC から約 62ms
遅れている**ことを意味する(日によって −30〜−75ms とドリフトもする —
図⑤)。重要なのはその差で、
**Lighter と Binance のサーバ時計どうしのずれは銘柄中央で ±2ms 以内**。
したがって server 時計での CCF は数 ms の精度で信頼でき、
local 時計(受信)版とも結論は変わらなかった(図の細部 CCF で両者を重ねて確認)。

- **同一秒内の共動が支配的**(k=0 で +0.33〜+0.83)。両者は同じ原資産を
  追っているので当然だが、その大きさ自体が「1 秒あれば互いに追いつく」ことを示す
- **日ずらしの帰無対照は全ラグで ±0.003 以内**に潰れる(図の灰)。
  観測された非対称は日周パターンでは説明できない
- 非対称の向きは**銘柄で割れる**:
  **米国メガキャップ(MSFT/NVDA/TSLA/AMZN)は Binance 先行**、
  **メモリ半導体(MU/SAMSUNG/DRAM/SKHYNIX)と銀は Lighter 先行**。
  SNDK・XAU・AAPL はほぼ互角

![細部 CCF](../../charts/lighter_ll_fine.png)

Δ=0.25s では**ピークは 12 銘柄中 11 で k=0**(MSFT だけ +0.25s)。
つまり伝播の大半は 250ms 以内に終わっており、
リードラグは「ピークの位置」ではなく**裾の非対称**として現れる。
server / local の両時計で形は一致する(時計の選び方で結論は変わらない)。

## 2. ★偏相関 — 相手は「自分の過去」を超える情報を持つか

自分の直前 1 秒のリターンを統制した、相手の直前 1 秒 → 自分の次の 1 秒の

| NVDA | +0.117 | 15/15 | +0.066 | 15/15 | Binance |

| AAPL | +0.067 | 15/15 | +0.057 | 15/15 | 互角 |

- **★両方向とも、全 12 銘柄・全日で正**(408 銘柄日で例外なし)。
  どちらの取引所も、相手の直前の動きに「自分の過去に無い情報」を持っている。
  一方通行の主従ではなく**相互に情報が流れている**
- 偏相関にすると生相関より**大きくなる**銘柄が多い(例: MU B→L +0.018 → +0.060)。
  自分の 1 秒リターンの負の自己相関(BBO バウンス)が生相関を抑えていた —
  Boros 報告⑰「約定フローは値動きに隠されていた」と同じ構造

### CCF の非対称(表 1)と偏相関(表 2)で順位が違う銘柄について

SAMSUNGUSD は CCF では Lighter 先行(シェア 0.18)なのに偏相関では B→L が強い。
CCF の Σρ は**遅いラグ(数秒〜10 秒)の裾**も足すのに対し、偏相関は
**直近 1 秒だけ**を見る。つまり SAMSUNG は「1 秒以内の応答は Binance の方が
予測的、数秒スケールの遅い追随は Lighter が先」という混合であり、
**単一の「リーダー」ラベルには集約できない**。両方の表を並べて読むこと。

## 3. 層別 — Lighter 先行は「米国立会の外」で起きる

| 銘柄 | US: k=+1 | US: k=−1 | OFF: k=+1 | OFF: k=−1 |
|---|---:|---:|---:|---:|
| MU | +0.012 | +0.005 | +0.017 | **+0.093** |
| SNDK | +0.023 | −0.014 | +0.048 | **+0.062** |
| NVDA | **+0.175** | +0.087 | **+0.192** | +0.089 |
| MSFT | **+0.222** | +0.021 | **+0.119** | +0.014 |
| XAU | +0.103 | +0.135 | +0.091 | **+0.150** |

- メモリ半導体の Lighter 先行(k=−1)は**立会時間外に集中**する
  (MU: OFF +0.093 対 US +0.005)。原資産が動いている立会中は両者とも速く、
  差が出ない。**原資産が閉まっている時間の価格発見が Lighter 寄り**で起きている
- メガキャップの Binance 先行は**両セッションで持続**(NVDA/MSFT)

## 4. ホライズン — Binance の直近 1 秒はどこまで先を当てるか

図④(上の方向判定の図)より、ρ(Binance 直近 1s, Lighter の h 先リターン)は
h=0.25〜1s が最大で、**MSFT は h=10s でも +0.15、h=60s で +0.05** と減衰が遅い。
活発な銘柄(MU/SNDK)は h=5s でほぼ消える。**薄い銘柄ほど取り込みが遅い**。

## 5. イベントスタディ — ジャンプは誰が追うか

片側の 1 秒リターンが max(3bp, その日の p99.9) を超えた瞬間(30 秒クールダウン)

| MU | +1.88bp | +0.62bp | +0.65bp |

(全 12 銘柄で同じ向き。n はペアあたり 620〜1,650 イベント)

★**非対称がはっきりしている**:

- **Binance のジャンプは「本物」扱い**: イベント終端までに Lighter は大半を
  織り込み、その後さらに +1.6〜+3.9bp を 1〜2 秒で追随する(全 12 銘柄で正)。
  Binance 自身はその後ほぼ動かない(+0.6bp 以下)= 行き過ぎではない
- **Lighter のジャンプは部分的に「ノイズ」扱い**: Binance の追随は最大 +0.6bp
  しかなく、薄い銘柄では Lighter 自身が**逆戻りする**(SAMSUNG −5.2bp、
  DRAM −1.8bp)。Binance と共有された成分だけが残り、Lighter 固有の
  行き過ぎは剥落する

## 自己精査

1. **損益に翻訳していない。**「Binance ジャンプ後の +2〜4bp」は spread 中央
   ~1bp より大きく見えるが、手数料・キュー・レイテンシ・イベント検知の遅延を
   一切引いていない。執行可能性の検証は別の作業
2. **時計**: server と local の両方で測り、両取引所のサーバ時計差が ±2ms 以内で
   あることを先に確認した(冒頭)。250ms より細かい主張はしない
   (Lighter は 50ms バッチ、Binance bookTicker はスロットル無し —
   到着粒度が非対称)
3. **帰無対照**: 日ずらしで全ラグ ±0.003 以内。巡回シフトでなく日ずらしを
   使ったのは、日周(米国立会)の共通性を対照に残すため
4. **単位**: 銘柄×日(408 銘柄日)。偏相関は 12 銘柄すべて・全日で正 —
   n=12 の符号検定の上限(z=3.46)には触れず、日単位の一致
   (15/15・19/19)を主な根拠とした
5. **「リーダー」は単一ラベルにできない**(§2 の SAMSUNG の例)。
   スケール(1 秒以内か数秒か)とセッションで向きが変わることを本文に明記
6. **イベントの選択**は Binance(または Lighter)の実現リターンに条件づけている。
   条件づけた側の「その後」は選択で歪む(だから読み取るのは**相手側**の応答)
