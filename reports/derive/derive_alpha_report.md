# ★上位ウォレットの実績を「技術」と「運」に分解する

[← Derive の分析索引](README.md)

## 何を測ったか

[MM 採算の検証](derive_mm_pnl_report.md)で、メイカー主体 41 ウォレットの実現損益
+$7.33M のうち **上位 3 者が 103%** を占めることが判った。この状況で平均を見ても
意味がない。問うべきは「**持続する wallet alpha があるか**」である。

wallet × day のパネルを組み、

$$ r_{i,t} = \alpha_i + \beta^\top X_{i,t} + \varepsilon_{i,t} $$

を推定する。i = ウォレット、t = 日。目的変数は 4 つを**別々に**:

| 記号 | 目的変数 |
|---|---|
| (a) | 純損益 / 名目 [bp] |
| (b) | 純損益 [$] |
| (c) | オプションのみ [$](反対売買 + 満期決済) |
| (d) | perp のみ [$] |

パネルは **275,656 行 / 23,150 ウォレット / 976 日**(2024-01-11〜2026-09-12)。

## 設計

### 共通ショックを落とす($X_{i,t}$ = 日固定効果)

相場が動いた日は誰でも勝つ/負ける。日ダミーを入れると $\alpha_i$ は
「**同じ日に他のウォレットより良かったか**」になり、
「たまたま vega を持っていた日に相場が動いた」分は日効果に吸われる。
日固定効果なしの素の推定も併記して、どれだけが共通要因かを見る。

### ★階層的縮約(empirical Bayes)

$\alpha_i \sim N(\mu_\alpha, \sigma_\alpha^2)$ を仮定し、標本の少ないウォレットの
見かけの大勝ちを 0 方向へ縮める:

$$ \alpha_i^{EB} = \mu_\alpha + B_i (\hat\alpha_i - \mu_\alpha), \qquad B_i = \frac{\sigma_\alpha^2}{\sigma_\alpha^2 + s_i^2} $$

$\sigma_\alpha^2$ はモーメント法($\mathrm{Var}(\hat\alpha) - \overline{s_i^2}$、下限 0)。
事後分散 $\tau_i^2 = (1/\sigma_\alpha^2 + 1/s_i^2)^{-1}$ から
$P(\alpha_i>0) = \Phi(\alpha_i^{EB}/\tau_i)$。

### ウォークフォワード

形成期 **6 か月**で順位を付け、続く **6 か月**で同じ順位が保たれるかを見る。
窓を 1 か月ずつ転がして **22 窓**。母集団は**結果を見る前に決めた**:
形成期・評価期の**両方で 20 日以上**活動したウォレットのみ。
帰無対照は評価期のウォレット標識を並べ替えて同じ統計を 500 回。

## 1. 結論

![技術と運の分解](../../charts/derive_alpha.png)

**上位 3 者のうち、技術と呼べる証拠があるのは 1 者だけ。**

| | ①`0x43a9880dA3` | ②`0x3bf64B8c8c` | ③`0x3aAa2bB57a` |
|---|---|---|---|
| 総実現損益 | +$3.66M | +$2.11M | +$1.81M |
| **P(α>0) 純損益** | 0.813 | **0.507** | 0.725 |
| **P(α>0) perp** | **0.997** | 0.564 | 0.663 |
| **縮約係数 B(純損益)** | 0.303 | **0.006** | 0.164 |
| perp アルファの順位 | **1 / 1,280** | 31 / 1,280 | 12 / 1,280 |
| ウォークフォワード出現 | **22 / 22 窓** | 7 窓 | 5 窓 |
| 評価期の順位(純損益・中央) | **0.99** | 0.01 | 0.98 |
| 評価期の順位(perp・中央) | **0.98** | **1.00** | 0.01 |
| 評価期の順位(オプション・中央) | 0.97 | **0.01** | 0.98 |

### ① `0x43a9880dA3` — 技術の証拠がある

- perp アルファ **+$3,562/日(縮約後)、P(α>0)=0.997、1,280 者中 1 位**
- **22 窓すべてに出現し、評価期の順位は中央 0.99**(常に上位 1%)
- 縮約係数 B=0.673(perp)は「素の推定の 67% を信用してよい」の意味
- 212,480 約定 / 889 日と標本が厚く、縮約に耐えた

**別期間で選んでも別期間で上位に残る。**これは運では説明しにくい。

### ② `0x3bf64B8c8c` — 大部分は「運」だが、構造は一貫している

ETH オプションのメイカー出来高 49% を占める最大手だが:

- 純損益の**縮約係数 B = 0.006**。素の日次アルファ +$5,574 が
  **縮約後 +$33 まで潰れる**。日次の振れが巨大で、+$2.11M は
  **運で説明できる範囲**に収まる。P(α>0)=0.507 = ほぼコイン投げ
- perp でも B=0.024、P=0.601。縮約に耐えない

**ただし「オプションで負けて perp で勝つ」構造は期間を通じて一貫している。**
評価期の順位は**オプション 0.01(最下位)/ perp 1.00(最上位)**。
これは運ではなく**設計**である。ただし設計が一貫していることと、
その設計が**正の期待値を持つこと**は別問題で、後者は確認できていない。

### ③ `0x3aAa2bB57a` — 判定不能

出現が **5 窓**しかなく、P(α>0)=0.725。評価期の順位は
純損益 0.98 と高いが、perp では 0.01。標本が足りない。

## 2. 市場全体 — 順位の再現性は無い。あるのは上位層の残存だけ

### Spearman rank IC(22 窓の中央値)

| 目的変数 | 素 | 日固定効果あり | 帰無の 95 分位 | 実測が帰無を超えた窓 |
|---|---:|---:|---:|---:|
| 純損益 [$] | +0.048 | +0.010 | +0.106 | **7/22**(素)/ 3/22 |
| オプションのみ [$] | +0.056 | +0.020 | +0.106 | 6/22 / 3/22 |
| perp のみ [$] | +0.059 | +0.006 | +0.110 | 8/22 / 3/22 |
| 純損益/名目 [bp] | −0.021 | −0.024 | +0.126 | 4/22 / 3/22 |

**どの目的変数でも、IC は帰無の 95 分位に届かない。**
日固定効果を入れると IC はほぼ 0 になる(3/22 窓 = 偶然の範囲)。
つまり**素の IC のわずかな正値も、その大半は共通ショック由来**だった。

★「有意でない」は「効果がない」ではない。22 窓は独立でもない(窓が重なる)。
ここで言えるのは「**ウォレット全体の順位が次の 6 か月に再現するという証拠は無い**」まで。

### 上位四分位の残存率

| 目的変数 | 実測 | 帰無 | 帰無の 95 分位を超えた窓 |
|---|---:|---:|---:|
| 純損益 [$] | **0.370** | 0.251 | **14/22** |
| 純損益/名目 [bp] | 0.332 | 0.252 | 9/22 |
| オプションのみ [$] | 0.299 | 0.269 | 3/22 |
| perp のみ [$] | 0.736 | 0.682 | 16/22 |

**上位四分位に入った者が次の 6 か月も上位四分位に残る確率は 0.370** で、
偶然の 0.251 を上回る(14/22 窓で帰無の 95 分位超え)。

★perp の 0.736 は帰無も 0.682 と高い。これは perp パネルのウォレット数が少なく、
四分位の区切りが粗いためで、**比較すべきは実測と帰無の差**(+0.054)である。
数字の大きさに引きずられてはいけない。

**要するにアルファは市場全体に散らばっておらず、上位層に局在している。**

## 3. 途中で潰した 2 つの自分のバグ

### (a) bp を単純平均すると壊れる

最初に日次 bp の**単純平均**でアルファを出したところ、1 位が
`0x2104654d6Da6`(+1,180 bp)になった。だがこのウォレットの
**総損益は −$133,523**。名目が極小の日の bp が効き過ぎていた。

→ **名目加重**($\sum \text{損益} / \sum \text{名目}$)に変更した。

### (b) 加重平均に非加重の標準誤差を当てて σ_α が 0 に潰れた

加重平均に切り替えた直後、$\sigma_\alpha = 0$ になり全ウォレットが
$\mu$ に完全縮約された。原因は $\hat\alpha$ を加重平均にしたのに
$s_i$ を非加重の $sd/\sqrt{n}$ のままにしていたこと。
$s_i$ が過大 → $\mathrm{Var}(\hat\alpha) - \overline{s^2} < 0$ → 0 で打ち切り。

→ 加重平均の分散式 $\mathrm{Var}(\hat\alpha) = \sum w^2 (x-\hat\alpha)^2 / (\sum w)^2$
に直した。$\sigma_\alpha$ は 48.34 bp に回復した。

## 4. ★別報告の訂正 — bp が 2 倍過大だった

[MM 採算の検証](derive_mm_pnl_report.md)で、ウォレット単位の名目を 2 で割っていた。
「1 約定が maker 行と taker 行の 2 行で返る」は**全ウォレットを合算したとき**の話で、
**特定のウォレットに絞れば自分の側の行しか出ない**(最大手は maker 78,116 行 /
taker 36 行)。

| | 誤 | **正** |
|---|---:|---:|
| メイカー主体 41 者の bp | +10.18 bp | **+5.09 bp** |
| ①`0x43a9880dA3` | +16.97 bp | **+8.48 bp** |
| ②`0x3bf64B8c8c` | +6.15 bp | **+3.08 bp** |
| ③`0x3aAa2bB57a` | +15.95 bp | **+7.97 bp** |

**ドル額・符号・感度分析の結論は変わらない。**bp 表示だけが 2 倍過大だった。
該当レポートは修正済み。

## 5. 自己精査

1. **上位 3 者は結果を見て選んだ集合である。**だからこそ別期間での追跡が要る。
   そして追跡すると 3 者の判定は割れた(22 窓 / 7 窓 / 5 窓)
2. **縮約は効いている。**②の純損益 B=0.006 は「素の推定の 0.6% しか信用しない」で、
   +$2.11M が運で説明できることを示す。縮約無しで見ていたら
   「3 者とも技術がある」と誤読していた
3. **分母を明示した。**bp は名目加重(§3a)。ドル建てと bp で結論が違う
   (①は bp では 2,618 者中 790 位 = 規模で稼いでいて単位効率では際立たない)
4. **帰無対照を置いた。**評価期の標識を 500 回並べ替え、IC と残存率の両方で比較
5. **★$s_i$ は日を独立と見なしている。**日内の相関や自己相関が残っていれば
   $s_i$ は過小で、**P(α>0) は楽観側**に出る。①の 0.997 も割り引いて読むべき
6. **窓は重なっている。**22 窓は独立ではないので、
   「14/22 窓で帰無超え」を二項検定にかけてはいけない
7. **venue 外は見えない。**①が Derive 外でどんな建玉を持っているかは判らない

### この分解が答えていないこと

- **なぜ①が勝てるのか**は判らない。速度か、在庫管理か、情報か、
  あるいは単に手数料ゼロの資格を持っているのか。本報告は「持続する」までしか言えない
- **②の設計が正の期待値を持つか**は未解決。構造の一貫性は示せたが、
  縮約に耐える正のアルファは検出できなかった
- **新規参入者が同じ成績を出せるか**は別問題
