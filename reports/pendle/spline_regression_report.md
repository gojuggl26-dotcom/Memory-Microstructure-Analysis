## 1. 毎イベントの板特徴量

オンチェーンのイベント列を再生し、**全イベント時点**で板の形を出した。

```
spread_pp       = best_short − best_long                        [pp]
mid_pp          = (best_short + best_long) / 2                  [pp]
book_slope_side = Σ_i |rate_i − best_side| · size_i / Σ_i size_i  [pp]
                  その側の流動性が自分の最良気配からどれだけ離れて置かれているか
book_slope_diff = book_slope_long − book_slope_short
```

| | 値 |
|---|---|
| イベント時点 | **27,253 行**(外挿区間を除き 26,963) |
| **検算** | 公式アーカイブの**最良気配** 1,070 断面と突合 → **不一致 0** |
| spread_pp | 中央 **0.2358**、p10 0.0417、p90 0.4713 |
| slope_long / slope_short | 中央 **0.7439** / **0.9862** |
| slope_diff | 中央 −0.0010、sd 1.6577 |

再生規則は `E:\Boros-history\scripts\mm_pnl.py` と同一。踏んではいけない罠 4 つ
(`filled` の from/to は**範囲**、注文 ID は **UInt64**、LONG は tick が**ビット反転**、
数量は **wei の int** のまま)はすべて継承した。

## 2. 模型

目的関数をそのまま実装した。3 次 B スプラインの 2 階微分は区分線形なので、
**罰則行列 Ω_jk = ∫B_j''B_k''dx は各ノット区間の 2 点ガウス求積で厳密**に組める。

```
β̂ = (BᵀB + λΩ)⁻¹ Bᵀy        有効自由度 = tr[ (BᵀB+λΩ)⁻¹ BᵀB ]
```

**λ は機械的に決める**: 連続する日で作った 5 フォールドの**時間ブロック CV**。
行のシャッフルは隣接イベントが相関するため使わない(METHODOLOGY §3)。

信頼帯は**日単位のブロックブートストラップ**(300 反復)。残差が自己相関するので
素の Bayesian 区間は狭すぎる。

## 3. ★途中で見つけて捨てた設計の欠陥 3 件

この分析は最初の設計では**全部が偽の結論になっていた**。記録する。

### (1) 窓の重なりで交差検証が壊れていた

全イベントを標本にすると、イベント間隔の中央値が **0 秒**(同一ブロックに固まる)なので
y = mid(t+h) − mid(t) の窓がほぼ完全に重なる。実測した自己相関は

| | lag1 |
|---|---:|
| 全イベントを使用 | **+0.980(600s)/ +0.995(3600s)/ +0.999(28800s)** |
| **間隔 h の重ならないグリッド** | **+0.195(600s)/ +0.295(3600s)** |

最初の版は前者で回し、**CV R² が全セルで負**になった。
**重ならないグリッド上で 1 点ずつ取る**設計に変更した。

### (2) フォールド間でボラが 8 倍違っていた

y の sd をフォールド別に見ると **0.068 〜 0.561**。
「当たる/外れる」が体制の分散に支配される。
**過去 20 点だけの移動 sd で割る因果的な標準化**(未来を見ない)を併記した。

### (3) R² の基準が実装不能な理想値だった

標本外 R² の分母に**試験フォールド自身の平均**を使っていた。
これはその時点では知りようがない量で、基準として不当に厳しい。
**訓練期間の平均**(実装可能な基準)に変更した。これだけで
R² が −0.13 → −0.00005 に動いた(600s / slope_diff)。

> 3 件とも**数字を見てから気づいた**。最初の出力(全セル負)は破棄した。

   **データが曲率をほとんど支持していない**ということ
4. `spread_pp` は 4 セル中 3 セルで edf ≈ 2.0(= 直線)。**曲がる余地すら無い**

## 5. なぜ検出できないのか — 標本の大きさ

先行案件と比べる。

| | DRAM(報告 43) | Boros 163 |
|---|---:|---:|
| 標本 | **8,451,761 行** | 1,069 〜 6,418 点(重なりを除いた実質) |
| `book_slope` の相関 | **−0.135**(98/98 日で同符号) | +0.077(3/5 フォールド) |
| 市場の活動 | BBO 更新 345,789 回/日 | イベント **599 回/日** |

**活動量が 500 倍違う。** n=1,069 での検出限界は 1.96/√n = **0.060**、
実測 +0.077 はかろうじて超えるが、**プラセボが ±0.13 まで振れる**ので実質的に届かない。

> **「関係が無い」のではなく「この 1 市場・44 日では判らない」**が正しい。
> 同じ効果量(相関 0.08)を確からしく検出するには、
> プラセボの散らばりから逆算しておよそ **4 倍の標本**が要る。
> 163 は 44.3 日で満期を迎えたので、**単独では絶対に足りない。**
