## 1. spread duration の定義と分布

各イベント時点で「`spread_pp` が最後に変化してからの経過秒」。
**時刻 t までの情報だけで決まる**ので時間契約に反しない。

7 市場 122,576 イベントの分布(図の右下):

| | 割合 |
|---|---:|
| ちょうど 0 秒(直前に変化) | **38%** |
| 1 分未満 | **51%** |
| 1 時間超 | **22%** |
| 最大 | 31 時間 |

**二極化している** — 大半は同一ブロック内の瞬間的な状態で、
一方で 2 割は数時間そのまま。裾が極端なので `log1p` で扱った。

## 2. 検証の設計

前報で潰した欠陥(窓の重なり・体制の不均一・R² の基準)はすべて継承したうえで、
**さらに 2 点を厳しくした**:

| | 内容 |
|---|---|
| **フォールド = 市場** | 1 市場を抜いて学習し、その市場で検証する。時間で切るより厳しく、「たまたまその市場だけ」を排除できる |
| **入れ子(nested)LOO** | λ を評価と同じ分割で選ぶと楽観側に偏る。**抜いた市場を見ずに、残り 6 市場の内部 LOO だけで λ を決めてから**評価する |

y は市場ごとに水準もボラも違うので、**過去 20 点だけの移動 sd** で標準化(因果的)。
プラセボは x を市場内で巡回シフト。

## 4. spread duration が駄目な理由 — 「標本不足」ではない

前報の `book_slope_diff` は「標本が足りなくて埋もれた」だったが、
**spread duration は性質が違う**:

1. **λ が両地平とも格子の最大(1e6)で選ばれ、edf = 2.0**。
   罰則の零空間は 1 次関数なので、これは
   **「データが曲率をいっさい支持していない」= 直線が最良**という意味である。
   束ねて標本を 5 倍にしても曲率が出てこない
2. **符号が地平間で反転する**(600s で +0.0076、3600s で −0.0472)。
   本物の関係なら地平を延ばして符号が変わることは考えにくい
3. **3600s では 7 市場中 1 市場でしか正にならない**。
   符号検定で 1/7 は、むしろ**負に一貫**していると読むほうが自然な水準
4. プラセボとの差もない(600s: +0.0076 対 −0.0075、3600s: −0.0472 対 +0.0291)

> **結論: spread duration は「まだ検出できない」のではなく、
> 「この標本で見るかぎり関係が無い」に近い。**
> ただし §7 のとおり、**別の使い方(生存分析そのもの)は否定していない**。

## 5. ★前報の訂正 — book_slope_diff は検出できる

前報(`spline_regression_report.md`)は市場 163 単独で
「実測の相関はすべてプラセボの幅の内側 = 検出できない」と結論した。
**7 市場に束ねたところ、明確に検出できた。**

| | 163 単独(前報) | 7 市場(本報) |
|---|---:|---:|
| 標本 | 1,069 点(3600s) | **4,955 点** |
| 相関 | +0.0774(3/5 フォールド) | **+0.1665(7/7 市場)** |
| プラセボ | +0.128(実測より大きい) | **−0.0225** |
| edf | 2.7 | **6.0** |

**符号検定は 7/7、二項検定で p = 0.0078**(片側)。
**しかも 600s と 3600s の 2 つの地平で独立に 7/7** である。

**曲線の形**(図の右上)は単調減少の **S 字**で、
`slope_diff` が −1 〜 +1 の範囲で急に効き、**両端では飽和する**。
DRAM 案件の `book_slope` が「裾で加速する」形だったのと**逆向き**で、
ここでは**中央に情報が集中し、極端な値は追加情報を持たない**。

## 6. 自己精査

- **§C-9**: spread duration を「効果なし」と断定していない。§4 のとおり
  「λ が最大罰則を選ぶ / 符号が反転する / 1 市場でしか正にならない」という
  **3 つの独立した徴候**を挙げて「関係が無いに近い」と書いた
- **§D-13/14 整合性**: 前報の結論を §5 で**明示的に訂正**した。
  訂正の方向は「検出できない → できる」で、前報の限界節に書いた原因(標本不足)と一致する
- **選択バイアス**: λ を評価と同じ分割で選ぶ問題を**入れ子 LOO** で潰し、
  両方の数字を併記した
- **帰無対照**: プラセボ(市場内で x を巡回シフト)を全セルに配置
- **検算**: 板の再生は 7 市場すべてでアーカイブ断面と**不一致 0**
- **★判定の単位**: 相関の大小ではなく**市場をまたぐ符号の一貫性(7/7)**を主判定にした。
  1 市場の数字が大きくても、他で再現しなければ採らない

## 7. 限界と、まだ試していないこと

| | |
|---|---|
| **spread duration の別の使い方は否定していない** | ここで測ったのは「duration → 将来の金利変化」だけ。**duration そのものの生存分析**(ハザード率、どんな状態が長続きするか)や、**約定の到来と duration の関係**は未検証 |
| KuCoin 7 市場のみ | Boros には 194 市場ある。Hyperliquid 89 / Binance 50 を足せば標本は 20 倍以上になる |
| AMM 側の流動性は含まない | オンチェーンログは CLOB のみ |
| 報酬目的の極小注文を分離していない | 取消率 94%、1 口座が発注の半分。`slope_diff` がこれに汚れている可能性は残る |
| 地平は 600s / 3600s のみ | 8 時間(決済周期)は標本数が足りない |
| **損益に翻訳していない** | 相関 0.17 は予測であって収益ではない。手数料・ガス・価格影響を引いていない |
