**建玉は休場日にほとんど動かない。** 出来高は 1/8.7 に落ちるのに OI 水準は 96% を保ち、
日次の建玉変化は立会日の約12％程度。休場日に起きているのは主に既存ポジションの
持ち回りで、新規の建て落ちは原市場が開いている間に集中している。原資産の価格発見が米国立会時間にしか起きないことの反映であり、この銘柄を扱う分析は立会日と休場日を必ず分けることが賢明である。不定期に祝日も存在するため曜日ダミーではなく取引所カレンダーを使う。

## 3. OI をどう作ったか(WORK_BUCKET に建玉のスナップショットが無いため)

`perp_and_spot_balances` を取得していないので、`node_fills` の `startPosition` から
ユーザーごとの建玉推移を復元した。

    pos_before = startPosition
    pos_after  = startPosition + (+sz if side=="B" else -sz)
    OI(t)      = Σ_user max(position, 0)

同一ユーザー・同一 ns に複数 fill があると行順が定まらないので、ns 単位でまとめ、
買い越しなら `entry = min(startPosition), exit = max(pos_after)`、
売り越しならその逆、として入口と出口を決めた。

### 検証

| # | 検証 | 結果 |
|---|---|---|
| V1 | `dir`(Open Long / Close Short / Long > Short …)と (startPosition, side) から導いた向きの一致 | **22,349,510 行すべて一致(100%)** |
| V2 | 多重グループで `exit == entry + Σd` | 片方向グループ(全体の 99.05%)の 98.5% で成立 |
| V3 | 約定を伴わない建玉の飛び | 全 14,312,014 遷移の **0.248%**、Σ\|飛び\| 245,030 枚(総取引量の 0.52%) |
| V4 | 窓開始のネット建玉(理論値 0) | **+2,934 枚**(当時の OI 49,438 枚の 5.9%) |
| V5 | ロング側とショート側を独立に復元したときの食い違い | 平均 ±2.0% / 最大 11%(07-30 に段差) |
| V6 | 外部突合(Hyperliquid 公開 API, 2026-08-27 時点) | 取引所公表 OI = 151,882 枚 / $148.5M。本復元の窓終端(08-10)は 105,539 枚 / $92.3M で、17 日後の公表値と桁・水準が整合 |

### 注意点

1. 窓期間中に一度も約定しなかったユーザーの建玉は観測できない。 V4 の +2,934 枚が
   その存在量の指標で、窓開始時点の OI の 5.9%である。
2. V3 の「飛び」(ADL・清算まわりと思われる約定を伴わない建玉変化)がロング側と
   ショート側の復元をずらす。図の帯はその半分を不確かさとして描いたもの。
   2026-07-30 に 14,000 枚の段差があり、それ以降は帯が広い(〜11%)。
3. Hyperliquidの取引は24時間であるため、OI は UTC 日の時間加重平均。米国立会時間だけの平均ではない。
