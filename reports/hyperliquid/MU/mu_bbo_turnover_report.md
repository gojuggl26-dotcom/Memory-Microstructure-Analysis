# xyz:MU 最良気配の入れ替わり(BBO turnover)

[← xyz:MU 分析索引](README.md)

最良気配がどれだけの速さで入れ替わるかを 9 つの指標で測る。
標本は 2026 年 5 月 4 日から 8 月 9 日の 98 日、
**bbo 3,516 万行 / 注文の線分 4 億 9,559 万本**(立会日 67 日 / 閉場日 31 日)。

## 1. 結論

数値は**日ごとの値の中央値**である(買い側。売り側もほぼ同じ)。

| | 指標 | 値 |
|---|---|---|
| ① | **bid BBO replacement count** | **1.32 回/秒**(1 日 11.4 万回) |
| ② | **ask BBO replacement count** | **1.33 回/秒** |
| ③ | **BBO lifetime** | 中央 **343ms**・平均 757ms・p90 1,611ms |
| ④ | **BBO wallet turnover** | **2.03 者/秒** |
| ⑤ | **BBO size turnover** | **0.15 回転/秒**(全部入れ替わるのに 6.6 秒) |
| ⑥ | **BBO order turnover** | **2.87 本/秒** |
| ⑦ | **best-price persistence** | 500ms で **0.574**、1 秒で 0.403 |
| ⑧ | **touch persistence** | 500ms で **0.513**、1 秒で 0.355 |
| ⑨ | **touch ownership duration** | 中央 **363ms**・平均 818ms・p90 1,754ms |

読みどころは 4 つある。

1. **最良気配は 1 秒もたない。** 価格が保たれる時間は中央 343ms、
   1 秒後も同じ価格である確率は 0.40 しかない。
2. **★注文は毎秒 2.87 本入れ替わるのに、数量は 0.15 回転/秒しか入れ替わらない。**
   19 倍の開きがある。**入れ替わっている注文は小さい**ということで、
   最良気配の厚みを作っている大きな注文はもっと長く居座っている。
3. **口座(2.03 者/秒)より注文(2.87 本/秒)のほうが速く入れ替わる。**
   同じ口座が注文を出し直しながら最良に留まっている。
   1 本の注文が最良に居る時間は中央 335ms、口座は 363ms と少し長い。
4. **価格が同じでも中身は入れ替わる。** 500ms で価格の持続 0.574 に対し
   中身の持続 0.513。差の 0.061 が「価格は動いていないのに
   そこに居る注文が総入れ替えになった」分である。

## 2. 定義

### なぜ格子を使わないか

最良価格が保たれる時間は**中央 343ms**(日次 min 139ms)で、
これまでのレポートで使ってきた 1 秒格子では短すぎて測れない。
そこで本レポートは**格子を一切使わず、区間の演算だけ**で ns 精度のまま測る。

| 用語 | 中身 | 出所 |
|---|---|---|
| **run** | ある価格が最良であり続けた時間区間 | bbo |
| **線分** | ある注文がその数量で板に載っていた時間区間 | l1 |
| **交差** | その注文が最良にあった時間区間 = 線分 ∩ 同じ価格の run | 両方 |

### 交差の求め方

同じ(側, 価格)の run は互いに重ならず時間順に並ぶので、開始も終了も単調である。
したがって線分 $`[t_0, t_1)`$ と重なる run は

```math
lo = \mathrm{searchsorted}(run の終了,\ t_0,\ \text{right}) \qquad
hi = \mathrm{searchsorted}(run の開始,\ t_1,\ \text{left})
```

で $`[lo, hi)`$ と一発で決まる。走査もループも要らない。

### 9 指標

| 指標 | 定義 |
|---|---|
| BBO replacement count | 最良価格が変わった回数 ÷ その日の観測時間[回/秒] |
| BBO lifetime | run の長さの分布 |
| BBO size turnover | 同じ価格が最良の間に消えた数量の累計 ÷ 平均数量 ÷ 時間[回転/秒] |
| BBO order turnover | 交差の本数 ÷ 最良が定義されていた総時間[本/秒] |
| BBO wallet turnover | 口座ごとに交差を和集合にした連結成分の数 ÷ 同[者/秒] |
| touch ownership duration | その連結成分の長さの分布 |

### ★持続の 2 つは同じ形で定義する

長さ $`L_i`$ の区間の集合に対して

```math
persistence(\Delta) = \frac{\sum_i \max(0,\ L_i - \Delta)}{\sum_i L_i}
```

とする。**best-price persistence** は run の長さ、**touch persistence** は
交差区間の長さに当てる。価格が同じでも中身は入れ替わりうるので、
必ず best-price ≧ touch になる。**この包含関係が検算になる。**

一度離れた価格が戻ってくる場合は「続いた」に数えない(下限として読むこと)。

### 母集団と板の再構成

[口座の集中度](mu_wallet_conc_report.md)や
[メイカーの混み具合](mu_maker_crowd_report.md)と同じ規則である。
トリガー注文とテイカー(`Ioc` など)を除いた `Alo` / `Gtc` の指値、
`reduce_only` は板に載るので含める。数量は 0.001 を 1 とする整数、
同一 ns の行順はゲート2 D4 の論理順で並べ直す。
24 時間まったく動きの無い注文は落とす。

## 3. 検算

### (1) 再構成した注文が最良を覆えているか

最良が定義されていた総時間のうち、再構成した注文の交差が覆っていた割合。
**最良気配には必ず誰かの注文があるはずなので、100% でなければ再構成が壊れている。**

| | 中央 | 最小 |
|---|---:|---:|
| 買い | **99.995%** | 99.541% |
| 売り | **99.993%** | 99.605% |

### (2) 持続の包含関係

| Δ | 10ms | 50ms | 100ms | 200ms | 500ms | 1s | 2s | 5s |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| best-price persistence | 0.987 | 0.935 | 0.876 | 0.772 | 0.574 | 0.403 | 0.247 | 0.109 |
| touch persistence | 0.985 | 0.923 | 0.853 | 0.735 | 0.513 | 0.355 | 0.222 | 0.089 |
| 差(価格は同じで中身だけ入替) | 0.002 | 0.012 | 0.023 | 0.037 | **0.061** | 0.048 | 0.025 | 0.020 |

**8 つの Δ すべてで best-price ≧ touch が成り立つ。** 定義上そうなるべきもので、
壊れていれば逆転する。

### (3) 買いと売りの対称性

置換回数 1.322 対 1.328、寿命の中央 343ms 対 347ms、
注文回転 2.865 対 2.929 と、どの指標も買い売りでほぼ一致する。
片側だけ壊れていれば崩れる。

## 4. 結果

### 4.1 最良価格はどれだけ変わるか

| | 中央 | 立会日 | 閉場日 | 日次 min | 日次 max |
|---|---:|---:|---:|---:|---:|
| 置換回数(買い)[回/秒] | 1.322 | **1.748** | **0.402** | 0.175 | 4.202 |
| 置換回数(売り)[回/秒] | 1.328 | 1.733 | 0.454 | 0.234 | 4.221 |
| BBO lifetime(中央)[ms] | 343 | 333 | 470 | 139 | 1,412 |
| BBO lifetime(平均)[ms] | 757 | 572 | **2,484** | 238 | 5,701 |
| BBO lifetime(p90)[ms] | 1,611 | 1,063 | **6,046** | 468 | 15,835 |

**立会日は閉場日の 4.3 倍の速さで最良価格が入れ替わる。**

**中央 343ms に対し平均 757ms** と 2 倍以上あり、分布は強く右に歪んでいる。
閉場日の平均は 2,484ms・p90 は 6,046ms まで伸びる。
**平均だけで語ると、長く止まっている時間帯に引っぱられる。**

### 4.2 ★3 つの回転率は桁が違う

| | 中央 | 立会日 | 閉場日 |
|---|---:|---:|---:|
| **order turnover**[本/秒] | 2.865 | 3.699 | 0.989 |
| **wallet turnover**[者/秒] | 2.030 | 2.788 | 0.731 |
| **size turnover**[回転/秒] | **0.151** | 0.233 | 0.057 |

**注文は毎秒 2.87 本入れ替わるのに、数量は 0.15 回転/秒しか入れ替わらない。**
数量が全部入れ替わるには 6.6 秒かかる計算で、注文の入れ替わりより **19 倍遅い**。

これは **入れ替わっている注文が小さい**ことを意味する。最良気配の厚みを
作っている大きな注文は、細かい注文の出し入れの下でもっと長く居座っている。
「最良気配が毎秒 3 回入れ替わる」という言い方は、
**厚みの入れ替わりとしては 19 倍過大**である。

注文(2.87)と口座(2.03)の比は **1.41** で、1 者が平均 1.4 本の注文を
出し入れしながら最良に留まっている。

### 4.3 誰がどれだけ最良を持っているか

| | 中央 | 立会日 | 閉場日 |
|---|---:|---:|---:|
| touch ownership duration(中央)[ms] | 363 | 329 | 562 |
| 同(平均)[ms] | 818 | 587 | 2,658 |
| 同(p90)[ms] | 1,754 | 1,247 | 6,541 |
| 1 本の注文が最良に居た時間(中央)[ms] | 335 | 271 | 418 |
| その日に最良を経験した口座数 | 374.5 | 466 | 197 |

**口座が最良に居続ける時間(363ms)は、1 本の注文が最良に居る時間(335ms)より
わずかに長い。** 注文を出し直して居座る動きはあるが、その効果は 8% ほどで、
**最良の保持はほぼ「1 本の注文が生きている間」に等しい。**

1 日あたり 374.5 者が最良を経験する。
[メイカーの混み具合](mu_maker_crowd_report.md)で見たとおり、
ある瞬間に最良を持っているのは 2.78 者しかいないので、
**顔ぶれは 1 日を通して大きく入れ替わっている。**

### 4.4 持続

500ms 先まで同じ最良価格が残っている確率は **0.574**、
中身まで同じ確率は **0.513**。1 秒では 0.403 と 0.355 に落ちる。

差(価格は同じなのに中身が入れ替わった分)は **500ms で最大の 0.061** になり、
その先は縮む。短い Δ では中身も変わる暇がなく、長い Δ では価格自体が
動いてしまうためで、**「価格は動かないが中身だけ入れ替わる」現象は
0.5 秒あたりが最も効く。**

## 5. 限界

1. **持続は「一度離れて戻る」を数えていない。** 同じ価格が最良に戻る場合を
   含めていないので、報告値は真の持続の**下限**である。
2. **板の深さは 1.24 倍に過大**([口座の集中度](mu_wallet_conc_report.md)の検算)。
   `filled` イベントを出さない約定が原因。**数量で測る指標
   (size turnover)はこの偏りを受ける。** 時間と本数で測る指標
   (置換回数・寿命・所有時間・持続)は受けない。
3. **BBO size turnover は bbo の数量の減少から測っている。** 約定による減少と
   取消による減少を分けていないので、「入れ替わり」には両方が入る。
4. **order turnover は「注文が最良に入った回数」である。** 同じ注文が
   価格の往復で複数回最良になれば、そのたびに数える。
5. **口座は `user` の一致で数えている。** 同じ主体が複数口座を使っていれば
   wallet turnover は過大に出る。
6. **記述統計であって予測ではない。** 入れ替わりの速さが将来の値動きや
   執行コストを教えるかは一切検証していない。
7. **1 銘柄である。** 銘柄横断の比較には他の 5 銘柄の `l1` と口座情報が要る。
