## 1. 結論

数値は断りのない限り**日ごとの値の中央値**である(裾が重く、平均は 1 日に
引っぱられるため。第 4.1 節に平均も併記する)。

| | 指標 | 値 |
|---|---|---|
| ① | **updates per second** | **111 通/秒**(日内 p99 675、最大 4,448) |
| ② | **NEW/sec** | 48 通/秒(全体の **43.3%**) |
| ③ | **REMOVE/sec** | 48 通/秒(**43.2%**) |
| ④ | **UPDATE/sec** | 0.11 通/秒(**0.10%**) |
| ⑤ | **messages per block** | **12.4 通**(中央 6、最大 1,453、CV 1.48) |
| ⑥ | **orders changed per block** | **12.0 本** |
| ⑦ | **inter-event duration** | **中央 72.2ms**(平均 112.3ms) |
| ⑧ | **event-duration variance** | **12,065 ms²**(σ 110ms) |
| ⑨ | **coefficient of variation** | **0.95** |
| ⑩ | **update burstiness** B | **−0.028**(立会日 −0.177 / 閉場日 +0.130) |
| ⑪ | **event clustering** M | **+0.217** |
| ⑫ | **Fano factor**(1 秒窓) | **172**(ポアソンなら 1) |
| ⑬ | **activity entropy** | **0.952**(正規化。1 で完全に平ら) |
| ⑭ | **activity autocorrelation** | ラグ 1 秒 **0.635** → 60 秒 0.424 → 1 時間 0.18 |

なお、この一群のもう一つの顔である `REJECTED`(板に一度も載らない拒否)は
**全メッセージの 13.5%** を占める。

読みどころは 3 つある。

1. **★「イベント間隔」はチェーンのブロック生成に量子化されている。**
   間隔の最頻値は 67.3ms とその整数倍(134ms、201ms)に並ぶ。この 67.3ms は
   99 日を通して **67.18〜67.50ms** の幅しかない。**間隔・分散・CV・burstiness は
   参加者の速さではなく「この銘柄に動きがあったブロックの間引き」を測っている。**
2. **群れているのは間隔ではなく 1 秒あたりの通数のほうである。** Fano factor は
   1 秒窓で 172、60 秒窓で 5,048。ポアソンの 1 から 3 桁離れている。
   自己相関は 1 時間先でも 0.18 残る。
3. **約定 1 件あたり 103 通・新規発注 47 本。** 立会日に限れば 127 通・58 本。

## 2. 定義と母集団

**板を作らないので除外は一切しない。** トリガー注文もテイカーも `...Rejected` も、
流れてきた以上はメッセージである。板の再構成を伴う他のレポート
([束の間の注文](mu_fleeting_report.md) / [口座の集中度](mu_wallet_conc_report.md) /
[ティック水準別 OBI](mu_obi_levels_report.md))とはここが違う。

| 種別 | 中身 |
|---|---|
| **NEW** | `open`(新規に板へ置かれた) |
| **REMOVE** | 各種 `canceled` と 残量 0 の `filled`(板から消えた) |
| **UPDATE** | 残量が残る `filled`(部分約定)と `triggered`(板に残ったまま変わる) |
| **REJECTED** | `...Rejected` 系(板に一度も載らない) |

指標の定義は次のとおり。ブロック間隔を $`\tau_i`$、窓長 T の計数を $`N_T`$、
1 秒ごとの通数を $`c_s`$ と書く。

```math
CV = \frac{\sigma_\tau}{\mu_\tau} \qquad
B = \frac{\sigma_\tau - \mu_\tau}{\sigma_\tau + \mu_\tau} \qquad
M = \mathrm{corr}(\tau_i,\ \tau_{i+1})
```
```math
F(T) = \frac{\mathrm{Var}(N_T)}{\mathrm{E}(N_T)} \qquad
H = -\sum_s p_s \ln p_s,\quad p_s = \frac{c_s}{\sum_u c_u}
```

B は Goh and Barabasi (2008) の burstiness で、ポアソン過程なら 0、
周期的なら −1、群れているなら +1 に近づく。M はその相方の記憶係数で、
短い間隔の後に短い間隔が続くかを見る。**event clustering はこの M と定義した。**
F(T) はポアソン過程なら窓長によらず 1 になる。
H は 1 日を 86,400 の秒に割った通数の分布のエントロピーで、
$`\ln(86400)`$ で割って正規化した。

## 3. ★ブロック時刻という制約 — 間隔の統計が何を測っているか

このデータの `ts` は **ブロックの時刻**で、同じブロックの事象はすべて同じ ns を持つ。
したがって

- **メッセージ単位の「イベント間隔」は同一ブロック内で 0 になり、意味を持たない。**
  間隔の統計はすべて**ブロック間隔**で測っている。
- ブロック間隔の分布は **67.3ms とその整数倍**に山が立つ(図④)。
  99 日すべてで 67.18〜67.50ms に収まり、**日による変動が 0.5% 未満**である。
  これはチェーンのブロック生成周期であって、市場の性質ではない。

つまり観測される間隔は

```math
\tau = 67.3\ \mathrm{ms} \times (この銘柄に動きがあるまでのブロック数)
```

という**間引き**の形をしている。忙しい日はほぼ毎ブロックに動きがあるので
間隔は一定に近づき、静かな日は間引かれて散らばる。実際

| | 立会日 | 閉場日 |
|---|---:|---:|
| 連続するブロック両方に動きがあった割合 | **66.1%** | **41.8%** |
| ブロック間隔の中央値 | 70.9ms | 132.6ms |
| burstiness B | **−0.177** | **+0.130** |

**立会日に B が負(ポアソンより規則的)になるのは、忙しくてブロック周期に
張り付いているからであって、参加者が規則的だからではない。**
B・M・CV・分散をこの市場の「バースト性」として読んではいけない。

群れを見たいなら、間隔ではなく**単位時間あたりの通数**(第 4.5 節の Fano factor)
か、**1 ブロックへの詰まり方**(第 4.3 節の CV 1.48)を見ること。

## 4. 結果

### 4.1 流量

| | 日次中央値 | メッセージ加重平均 | 最大 |
|---|---:|---:|---:|
| updates per second | 111 | 285 | — |
| 日内 p99 | 675 | 1,218 | — |
| 日内の最大の秒 | — | — | **4,448 通** |

立会日 173 通/秒 に対し閉場日 26 通/秒 で、**6.5 倍**の差がある。
1 日の 86,400 秒のうち、メッセージが 1 通も無い秒は中央で 770 秒しかない
(99.1% の秒に何かが流れている)。

### 4.2 種別の内訳

| 種別 | 割合(日次中央) | 割合(加重平均) |
|---|---:|---:|
| NEW | 43.3% | 42.8% |
| REMOVE | 43.2% | 42.7% |
| UPDATE | 0.10% | 0.09% |
| **REJECTED** | **13.5%** | **14.4%** |

NEW と REMOVE がほぼ同数なのは当然で、置かれた注文はいずれ消えるからである。
**UPDATE が 0.1% しかない**のは、この板では部分約定がほとんど起きず、
注文が「置かれて消える」だけの存在であることを意味する
([束の間の注文](mu_fleeting_report.md)の結論と整合する)。

**7 通に 1 通は拒否である。** 内訳の上位は `perpMarginRejected` と
`badAloPxRejected`(post-only 指定なのにクロスする価格へ出した)で、
どちらも「出す前に判る条件で弾かれている」種類の無駄な発注である。

### 4.3 ブロックへの詰まり方

1 ブロックあたり **12.4 通**(中央 6 通、最大 **1,453 通**、CV **1.48**)。
そのうち**動いた注文は 12.0 本**で、1 つの注文が同じブロックで複数のメッセージを
出すことは稀である(12.4 / 12.0 = 1.03 通)。

CV 1.48 は、ブロックによって詰まり方が大きく違うことを示す。
**ここに市場側のバースト性が出ている。**

### 4.4 間隔とそのばらつき

| | 値 |
|---|---:|
| inter-event duration(中央) | 72.2ms |
| 同(平均) | 112.3ms |
| event-duration variance | 12,065 ms² |
| σ | 110ms |
| coefficient of variation | 0.95 |
| ブロック周期 | **67.3ms** |

CV が 1 に近いのは指数分布的ということだが、第 3 節のとおりこれは
**幾何分布的な間引き**の結果であって、到着がランダムだという意味ではない。

### 4.5 群れ(burstiness / clustering / Fano)

| 窓長 | 10ms | 50ms | 100ms | 500ms | 1s | 5s | 10s | 60s |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| **Fano factor(1 日)** | 48 | 42 | 46 | 108 | **182** | 588 | 1,026 | 5,048 |
| Fano factor(最繁 1 時間) | 69 | 53 | 52 | 93 | **147** | 382 | 610 | 2,416 |

**どの窓長でもポアソンの 1 から 1〜3 桁離れている。**
100ms 以下でほぼ平ら(42〜48)なのは、ブロック周期より短い窓では
「その窓にブロックが入ったか」を測っているためである。
**500ms を超えると単調に増える**のが本物の群れで、
窓長に対して概ね比例して増える(長期記憶の形)。

最繁 1 時間に限っても 1 秒窓で 147 ある。**日内の繁閑を取り除いても群れは残る。**

burstiness B は中央 −0.028、memory M は +0.217。図⑤ の B-M 平面では、
立会日(青)が左下から中央へ、閉場日(橙)が右上に伸びる弧を描く。
**この弧は活動量の違いであって、市場の性質が日で変わったのではない**
(第 3 節)。

### 4.6 エントロピーと自己相関

正規化エントロピーは **0.952**(1 なら 86,400 秒すべてに均等)。
最も忙しい 1% の秒(864 秒)が全メッセージの **6.9%** を占める。
均等なら 1% なので **7 倍の偏り**だが、「ごく一部の秒に集中している」
と言えるほどではない。

自己相関は ラグ 1 秒 0.635 → 2 秒 0.479 → 10 秒 0.406 → 60 秒 0.378 →
300 秒 0.339 → **3600 秒でも 0.183**。**指数的には減らない。**
忙しさは分単位・時間単位で持続する。

## 5. quote stuffing はあるか

| | 日次中央 | 立会日 | 閉場日 |
|---|---:|---:|---:|
| **メッセージ / 約定 1 件** | **103** | 127 | 53 |
| **新規発注 / 約定 1 件** | **47** | 58 | 31 |

約定 1 件を生むのに 47 本の指値が出され、103 通のメッセージが流れる。
[束の間の注文](mu_fleeting_report.md)で示したとおり、そのうち 2 秒以内に
消えるのが数量の 66.4% である。**板は約定のためというより、
場所取りと引き上げのために使われている。**

ただし、**単独の主体による意図的な stuffing の証拠は見つからない。**
最も忙しい秒(日ごとの上位 10 秒、計 990 秒)について、その秒のメッセージが
1 つの口座に集中している割合を測ると

| | 値 |
|---|---:|
| 1 口座が占める割合の中央値 | **13.2%** |
| 同 最大 | 76.8% |
| 最も忙しかった秒(2026-08-06) | 4,448 通、うち最大の口座 25.2% |

**バーストはたいてい市場全体で起きており、1 者が撃っているのではない。**
最大 76.8% の秒は存在するので、個別に見れば単独主体のバーストもある。

## 7. 限界

1. **間隔まわりの 4 指標(⑦⑧⑨⑩)はチェーンの制約を強く受ける**(第 3 節)。
   他の取引所や他のデータ源と比べるときは、ブロック周期を揃えないと
   意味のある比較にならない。
2. **メッセージは xyz:MU に関するものだけ**である。同じブロックに他銘柄の
   メッセージが入っていても、このファイルには現れない。したがって
   「連続ブロック率」は MU の活動度であって、チェーンの稼働率ではない。
3. **REJECTED の内訳は分けていない。** 拒否理由ごとの流量は別途数える必要がある。
4. **記述統計であって予測ではない。** 流量が将来の値動きやボラティリティを
   教えるかは一切検証していない。
5. **口座の集中は最繁 10 秒しか見ていない**(第 5 節)。全時間帯での
   メッセージ発信者の集中度は測っていない。
6. **1 銘柄である。** 銘柄横断の比較には他の 5 銘柄の `l1` が要る。
