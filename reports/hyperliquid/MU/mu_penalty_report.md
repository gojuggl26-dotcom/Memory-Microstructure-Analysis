# xyz:MU — SelectionPenalty(S,D):約定という条件が alpha をどれだけ壊すか

    SelectionPenalty(S,D) = E[r_{T→T+h} | Fill, S, D] − E[r_{T→T+h} | S, D]

図: `xyz_MU_penalty_obi.png` / `xyz_MU_penalty_ofi_10s.png` /

![xyz MU penalty obi](../../../charts/xyz_MU_penalty_obi.png)
![xyz MU penalty ofi 10s](../../../charts/xyz_MU_penalty_ofi_10s.png)
`xyz_MU_penalty_ai_net_10s.png`(信号 S1..S10 × 待ち行列 D1..D10)

**両方とも同じ窓 T→T+h で測る。** 約定時刻 τ 起点にすると約定しなかった側が
定義できず比較にならないので、ここだけは発注時刻 T 起点で揃えてある
(逆選択そのものの大きさは [約定時刻から測った AS と EV](mu_ev_report.md) を見ること)。

---

## 0. 結論を先に

> **【定義の確認 — 2026-09-01】** 本報告の SelectionPenalty は窓が **T→T+h**、
> [EV の報告](mu_ev_report.md)の AS は窓が **τ→τ+h** で、**別の量である**。
> 数値が −2.8〜−5 と −1.25 で違うのは当然で、矛盾ではない。
> 恒等式による検算と、A = r(T→τ) / B = r(τ→τ+h) への分解は
> [3 分解の報告](mu_markout_report.md) を見ること。
> なお本報告の「−3〜−5 bp」は**セルごとの値**で、全セルをプールすると **−2.82 bp**。


**alpha は約定という条件だけで、平均して 16 倍の大きさで消える。**

| | h = 10 秒・買い指値 |
|---|---|
| 誤差を付けて検査したセル | **1,717** |
| SelectionPenalty < 0 | **1,717 / 1,717**(全部) |
| うち日次 Newey-West で t < −3.29(Bonferroni) | **1,715** |
| SelectionPenalty > 0 かつ有意 | **0** |
| penalty の範囲 | **−7.03 〜 −1.23 bp**(中央 −2.86) |
| 無条件 alpha が正のセルでの \|penalty\| ÷ alpha | 中央 **15.9 倍**、最大 57.7 倍 |

**最も破壊されるのは「自分がクオートしたい向きに信号が出ている状態」である。**
買い指値なら S10(最も買い側)、売り指値なら S1(最も売り側)で最悪になる。

ユーザーの例と同じ形で書くと、OBI の S10(h=10 秒、D で平均):

    無条件 = +0.560 bp
    約定時 = −4.135 bp
    SelectionPenalty = −4.694 bp

## 2. なぜこれが中心指標になるか

信号の善し悪しを無条件のリターンで測ると、**受動的に執行する限り
その数字は一度も手に入らない**。OBI の S10 は無条件で +0.56 bp の
alpha を示すが、そこで買い指値を出して約定した集合では −4.14 bp である。

つまり「信号があるか」と「その信号で儲かるか」の間に、
**約定という条件づけだけで平均 16 倍、最大 58 倍の落差**がある。
どの指標をどう組み合わせても、この落差を跨げなければ意味がない。

---

## 3. 言えないこと

- **これは受動的執行に固有の話である。** 板を叩いて取る場合には
  SelectionPenalty はかからない(代わりにスプレッドを払う。
  [予測レポート §5](mu_prediction_report.md) で 32 通りすべて赤字)
- **取り消しを一切していない。** 不利になったら引く運用なら
  約定集合そのものが変わる。ここで測ったのは「置きっぱなし」の値である
- **penalty は h とともに単調に大きくなる。** 保有時間を短くすれば
  絶対値は小さくなるが、[EV の報告](mu_ev_report.md)のとおり
  100 ミリ秒でも半スプレッドを賄えない
- **銘柄は xyz:MU のみ**、標本 97 日
