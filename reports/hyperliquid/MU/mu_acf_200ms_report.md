# OBI と OFI の自己相関(200ms 格子)

[← xyz:MU の分析索引](README.md) ／ [用語辞書](../../../GLOSSARY.md)

対象 `xyz:MU` ／ 標本 2026-05-04 〜 2026-08-09 の 98 日(立会日 67 / 閉場日 31)

板の残高の偏り([OBI](../../../GLOSSARY.md))と流量の偏り([OFI](../../../GLOSSARY.md))を
200ms の時計に載せ直し、それぞれの自己相関を 200ms から 5 分までのラグで測りました。
結論を先に書くと、**OBI の高い自己相関はほぼ標本化の副作用**で、
**OFI は実質的に無記憶**です。

![OBI と OFI の自己相関](../../../charts/xyz_MU_acf_200ms.png)

---

## 1. なぜ格子に載せ直すか

OBI と OFI はイベント時刻(最良気配が動いた瞬間)にしか定義されていません。
イベントの間隔は一定でないので、そのまま並べた自己相関は
「200ms 後との相関」ではなく「次のイベントとの相関」になります。
時計で 200ms ごとに測り直します。

載せ方は 2 つの量で違います。

| | 種類 | 格子点 T の値 |
|---|---|---|
| OBI | **状態** | T 以前の最後のイベントの OBI。イベントが無い区間は直前の値を持ち越す |
| OFI | **流量** | 区間 (T−200ms, T] のイベントの OFI の合計。イベントが無ければ 0 |

空区間の OFI が 0 になるのは「何も起きなかった = 流量ゼロ」で、事実として正しい扱いです。
一方 OBI の持ち越しには副作用があり、それが第 3 節の主題になります。

クロスした板の行(`best_ask ≤ best_bid`)と数量 0 の行は除外しています(19,186 行)。

## 2. 結果

日ごとにラグ $`k`$ の標本自己相関

```math
\rho_k = \frac{\sum_t (x_t - \bar{x})(x_{t+k} - \bar{x})}{\sum_t (x_t - \bar{x})^2}
```

を出し、日を単位にしたブートストラップ(400 反復)で区間を付けました。
格子点どうしは強く相関しているので、点を単位にした区間は狭すぎます。

| ラグ | OBI 立会日 | OBI 閉場日 | OFI 立会日 | OFI 閉場日 |
|---|---:|---:|---:|---:|
| 0.2s | +0.680 | +0.890 | +0.0196 | +0.0406 |
| 1s | +0.360 | +0.720 | +0.0065 | +0.0224 |
| 5s | +0.177 | +0.463 | +0.0038 | +0.0040 |
| 10s | +0.130 | +0.338 | +0.0040 | +0.0050 |
| 30s | +0.078 | +0.198 | +0.0024 | +0.0032 |
| 60s | +0.056 | +0.148 | +0.0017 | +0.0059 |
| 300s | +0.025 | +0.068 | **+0.0004** | +0.0037 |

95% 区間が 0 を含むのは太字の 1 セル(OFI 立会日 300s、[−0.0001, +0.0008])だけです。
ただし報告している区間は **156 ラグ × 2 変数 × 2 日区分 = 624 件**あるので、
1 件あたり 5% 水準で読むのは緩すぎます。Bonferroni なら 0.008% 水準が要ります。
OBI 側は桁が違うので影響を受けませんが、**OFI の 5 秒より先を「有意」と強く主張はできません**。

## 3. ★ OBI の高い自己相関は、ほぼ標本化の副作用

200ms 格子のうち最良気配が一度も動かない空区間は **中央値 44.1%**(最小 8.4%、最大 88.6%)あります。
そこでは OBI が定義上そのまま持ち越されるので、更新の少ない日ほど自動的に自己相関が上がります。

日ごとに並べると、**空区間の割合と 1 ラグ自己相関はほぼ一直線**に乗ります(図 C)。

| | 空区間の割合 | OBI の 1 ラグ自己相関 |
|---|---:|---:|
| 立会日(67 日) | 36.0% | +0.680 |
| 閉場日(31 日) | 73.7% | +0.890 |

日を単位にした相関は **ピアソン +0.970 / スピアマン +0.977**。
つまりこの指標は「板が粘っている度合い」ではなく、ほぼ
**「何も起きなかった頻度」**を測っています。
閉場日のほうが自己相関が高いのも、板が粘るからではなく更新が少ないからです。

200ms という固定時計で測る限りこれは避けられないので、
特徴量には区間ごとのイベント数 `n_ev` を同梱しました。
板そのものの粘りを見たい場合は、イベントのあった区間に限るか、
イベント時計で測り直す必要があります(本レポートの範囲外)。

OFI 側にはこの問題がありません。空区間の流量 0 は事実だからです。

## 4. OFI は無記憶で、日によって符号が変わる

OFI の自己相関は 200ms で +0.0196、1 秒で +0.0065、それより先は 0.006 以下です。
**流量には持続が無い**と読めます。

ただし日ごとのばらつきが大きく、符号が安定しません(図 D)。

| | 値 |
|---|---:|
| 最小 | −0.1933 |
| 第 1 四分位 | −0.0112 |
| 中央 | +0.0218 |
| 第 3 四分位 | +0.0683 |
| 最大 | +0.2094 |
| 負の日 | **30 / 98 日** |

「平均としては弱く正、日によって符号が変わる」が正確な記述です。

## 5. 帰無対照は「並べ替え」であって「巡回シフト」ではない

このリポジトリの他のレポート([MicroPrice](mu_microprice_report.md)、
[OBI と OFI](mu_obi_ofi_report.md) など)では日内の巡回シフトを帰無対照に使っています。
しかしそれは **x と y の対応だけを壊す道具**であって、
**自己相関には効きません**。系列を回しても自分自身との相関はそのまま残るからです。

ここでは日内で無作為に並べ替えました。時間の順序が消えるので自己相関は 0 に潰れるはずで、
実測は全セルで OBI |ρ| ≤ 0.0011、OFI |ρ| ≤ 0.0009 でした。推定量そのものは健全です。

`*_rho1_60s` / `*_rho1_5m` は **T で終わる後ろ向き窓**(60 秒 / 5 分)の中だけで計算した
1 ラグ自己相関なので、そのまま説明変数に使えます。`shift(-k)` は使っていません。

一方、本レポートの自己相関表は**日内平均で中心化した記述統計**です。
標本外評価に使うなら中心化も窓の中でやり直す必要があります。

## 7. 踏んだ誤り

動作確認を `--days 3` で行い、**それが上場直後の 3 日だった**ため、
OFI の 1 ラグ自己相関が −0.107 と出ました。全 98 日では +0.0196 で符号が逆です。
先頭 N 日は標本として代表性が無く、動作確認の結果をそのまま見込みとして報告したのが誤りでした。
図 D の灰色の帯がその 3 日です。
