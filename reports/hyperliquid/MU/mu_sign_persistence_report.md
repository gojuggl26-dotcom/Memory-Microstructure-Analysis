# xyz:MU 特徴量の符号は何イベント先まで持続するか

このリポジトリでこれまでに算出した特徴量について、**符号が正のとき k イベント後も
正である確率**を推移確率行列にした。k は 1 から 5 まで。標本は 2026 年 5 月 4 日から
8 月 9 日までの 98 日、最良気配(BBO)イベント 35,169,386 件である。

再現: `uv run python scripts/build_sign_persistence.py --coin xyz:MU`
図の再生成: `uv run python scripts/plot_sign_persistence.py --coin xyz:MU`

![符号の持続性](../../../charts/xyz_MU_sign_persistence.png)

## 0. ★この数字は「予測力」ではない

先に釘を刺しておく。ここで比べているのは $\mathrm{sign}(x_t)$ と
$\mathrm{sign}(x_{t+k})$、つまり**同じ特徴量どうし**である。測っているのは
x 自身の符号の自己相関であって、将来の価格を当てる力ではない。

「OBI が正なら次も正である確率が 74.9%」は、**OBI が正なら価格が上がる確率**では
まったくない。価格の予測力については
[OBI と OFI から見た上昇確率](mu_obi_ofi_report.md) と
[予測の定義](../../predicting_definition.md) を参照すること。あちらでは同じ
説明変数の予測確率が 5 割前後で、かつ**スプレッドを超えない**ことを示している。

本レポートは取引の根拠にならない。費用(手数料・スプレッド・スリッページ)も
一切控除していない。控除する対象となる取引を提案していないからである。

### 時間契約

| | 確定する時刻 |
|---|---|
| $\mathrm{sign}(x_t)$ | $t$ |
| $\mathrm{sign}(x_{t+k})$ | $t+k$ |

両方とも説明変数側であり、目的変数を含まない。`shift(-k)` は使っていない。
先読みは構造的に起こり得ない。

---

## 1. 定義

特徴量 x の符号を 3 状態 $\{-, 0, +\}$ に落とし、k イベント後の符号との
同時分布を数える。

$$N_k[s, s'] = \#\{\, t : \mathrm{sign}(x_t) = s \;\wedge\; \mathrm{sign}(x_{t+k}) = s' \,\}$$

$$P_k[s, s'] = \frac{N_k[s, s']}{\sum_{s''} N_k[s, s'']}$$

主役は右下のセル $P_k[+, +]$ である。

$(t, t+k)$ の組は**同じ日の中だけ**で作る。日の最初の行は前の行が前日なので、
差分で作る特徴量(OFI・Δスプレッド・Δ数量・リターン)はそこで無効にする。

### 対象にした特徴量

| 特徴量 | 定義 | 時計 |
|---|---|---|
| OBI | $(q^b - q^a)/(q^b + q^a)$ | BBO イベント |
| BookSlope | $(q^b - q^a)/h$、$h$ は半スプレッド[bp] | BBO イベント |
| micro_dev | $\mathrm{micro} - m$ | BBO イベント |
| OFI | Cont–Kukanov–Stoikov (2014) | BBO イベント |
| Δスプレッド幅 | $s_t - s_{t-1}$ [bp] | BBO イベント |
| Δ最良気配数量 | $(q^b + q^a)_t - (q^b + q^a)_{t-1}$ | BBO イベント |
| mid のリターン | $\log m_t - \log m_{t-1}$ | BBO イベント |
| テイカーの向き | 買い = 正、売り = 負 | **成行注文** |

### ★載せられなかった特徴量

スプレッド幅・最良気配の合計数量・約定量・注文サイズ・到着深さは**定義上つねに
正**である。$P(+) = 1$ となって推移行列が退化するので、そのままでは載せられない。
向きに意味があるのは変化のほうなので、差分をとった Δスプレッド幅・Δ最良気配数量を
代わりに置いた。

### ★イベントの時計が 2 種類ある

BBO 系は「最良気配が変わった 1 行」を 1 イベントと数える(98 日で 35,169,386 件)。
テイカーの向きは「成行注文 1 本」を 1 イベントと数える(6,372,171 本)。
**同じ k でも指す実時間が 5〜6 倍違う**ので、この 2 つの間で k を横に比べてはならない。
成行注文単位の定義は
[攻撃的な売買の向きの推移確率行列](mu_sign_chain_report.md) に合わせてある。

生の確率をそのまま読んではいけない理由は第 3 節に書く。持続性は次の量である。

$$\text{持続性} = \underbrace{P_k[+,+] - P_k[\cdot,+]}_{\text{超過}} - \underbrace{\text{帰無対照}}_{\text{集計の偏り}}$$

| 特徴量 | k=1 | k=2 | k=3 | k=4 | k=5 |
|---|---:|---:|---:|---:|---:|
| OBI = BookSlope = micro_dev | **+25.59** | +18.51 | +14.42 | +12.06 | +10.33 |
| テイカーの向き | **+15.65** | +12.56 | +10.56 | +9.37 | +8.48 |
| OFI | **+9.88** | +8.00 | +6.68 | +5.66 | +4.68 |
| mid のリターン | **+7.48** | +6.96 | +5.93 | +5.06 | +4.23 |
| Δスプレッド幅 | **−4.82** | −0.32 | +0.72 | +1.17 | +1.48 |
| Δ最良気配数量 | **−7.64** | −2.22 | −1.13 | −0.36 | −0.08 |

### 読み取れること

1. **板の残高の偏り(OBI)が最も持続する。** k=1 で +25.6pp。5 イベント先でも
   +10.3pp 残り、40% が生き残っている。半減するのは k ≈ 3.7 のあたり。
2. **残高(OBI)は流量(OFI)の 2.6 倍持続する。** これは
   [OBI と OFI レポート](mu_obi_ofi_report.md) の「2 つは水準と差分であって別物」
   という主張と整合する。差分は定義上ほとんど記憶を持たない。
3. **Δスプレッド幅と Δ最良気配数量だけ k=1 で負になる。** 広がった直後は縮み、
   厚くなった直後は薄くなる。板の量は跳ね返る。
4. **Δスプレッド幅は k=3 で符号が正に転じる。** 直後は反転するが、少し先を見ると
   同じ向きが続く。k=2 は 0 と区別できない(第 7 節)。
5. **Δ最良気配数量は 5 イベント先でも 0 に戻り切らない**(−0.08pp、95% 区間
   [−0.13, −0.03])。ただし大きさは k=1 の 1/91 で、実質的にはほぼ消えている。

## 3. ★対照は 0.5 ではない

特徴量の符号は 50:50 ではない。無条件の $P(+)$ は OBI で 49.22%、テイカーの向きで
53.04%、mid のリターンでは 30.37% しかない(残りの大半は「ちょうど 0」)。

$P_k[+,+] = 0.62$ という数字は、無条件の $P(+)$ が 0.62 なら持続性が**ゼロ**である
ことを意味する。したがって比較対象は 0.5 ではなく、**同じペア集合の上での列周辺確率**
$P_k[\cdot,+]$ である。k が変わるとペア集合も変わるので、周辺は k ごとに取り直す。

### 帰無対照 —— 日内で無作為に並べ替える

日の中で符号列を無作為に並べ替える。周辺分布はそのままで、時間の対応だけが壊れる。
持続性が本物なら超過は 0 へ潰れるはずである。

**★巡回シフトは使えない。** 巡回シフトは自己相関を保存するが、ここで測っている
のがその自己相関そのものだからである。他のレポート
([OBI と OFI](mu_obi_ofi_report.md) 等)で巡回シフトを使っているのは、x はそのまま
で y との対応だけを壊すのが目的のときであり、目的が違う。

### ★帰無対照は 0 に潰れ切らない

| 特徴量 | 生の超過 (k=1) | 帰無対照 | 持続性 |
|---|---:|---:|---:|
| OBI | +25.69 | **+0.10** | +25.59 |
| テイカーの向き | +15.96 | **+0.31** | +15.65 |
| OFI | +9.88 | **+0.00** | +9.88 |
| mid のリターン | +8.79 | **+1.31** | +7.48 |
| Δスプレッド幅 | −3.87 | **+0.95** | −4.82 |
| Δ最良気配数量 | −7.53 | **+0.11** | −7.64 |

0 でない理由は**全日を合算したことによる集計の偏り**である。日ごとに $P(+)$ が違う
まま条件付き確率を合算すると、正の多い日が分子側に重く効く。$P(+)$ の日間ばらつきが
大きい特徴量ほど偏りも大きく、mid のリターンで +1.31pp、Δスプレッド幅で +0.95pp に
達した。

したがって持続性は生の超過からこの分を引いて読む。**引く前と後で結論が変わる例が
実際にある。**

- Δスプレッド幅 k=2 は生の超過が **+0.62pp(正)** だが、補正後は **−0.32pp(負)** で
  符号が反転する
- Δ最良気配数量 k=5 は生の超過が **+0.02pp**、つまり「ほぼ 0 で符号は正」に見えるが、
  補正後は **−0.08pp** で負である

帰無対照を置かなければ、この 2 つは向きを取り違えたまま報告していた。

## 4. ★3 状態を 2 状態に潰さない

「ちょうど 0」は実在する。潰すとその分がどちらかの側に混ざり、持続性が水増しされる。

| 特徴量 | 負 | ちょうど 0 | 正 | 0 の割合 |
|---|---:|---:|---:|---:|
| OBI | 17,385,220 | 473,905 | 17,310,163 | 1.35% |
| テイカーの向き | 2,951,827 | 0 | 3,334,357 | 0.00% |
| OFI | 17,288,898 | 84,633 | 17,795,659 | 0.24% |
| mid のリターン | 10,595,280 | **13,891,866** | 10,682,044 | **39.50%** |
| Δスプレッド幅 | 12,848,364 | **13,575,429** | 8,745,397 | **38.60%** |
| Δ最良気配数量 | 16,856,810 | 1,131,934 | 17,180,446 | 3.22% |

mid のリターンと Δスプレッド幅は **4 割近くがちょうど 0** である。最良気配が
変わっても mid も spread も動かないイベント(片側の数量だけが変わった等)が
それだけ多い。ここを潰したら数字の意味が失われる。

OBI の 1.35% は[OBI と OFI レポート](mu_obi_ofi_report.md)が別途報告している
「ちょうど 0 の帯は全体の 1.35%」と一致する。テイカーの向きに 0 が無いのは
買いか売りしかないからで、定義どおりである。

### OBI の完全な推移行列(k=1)

行の合計が 100%。

| 今 \ 1 イベント後 | 負 | ちょうど 0 | 正 |
|---|---:|---:|---:|
| 負 (17,385,220) | **75.0%** | 1.2% | 23.8% |
| ちょうど 0 (473,905) | 43.9% | **11.8%** | 44.3% |
| 正 (17,310,163) | 23.9% | 1.2% | **74.9%** |

負と正はほぼ対称(75.0% と 74.9%)である。中央行が興味深い。**ちょうど 0 の状態は
次も 0 である確率が 11.8% あり、無条件の 1.35% の 8.8 倍**である。両建てで同数量を
出している気配は、次のイベントでもその状態を保ちやすい。2 状態に潰すとこの構造は
まるごと消える。

## 5. ★3 つの特徴量は符号として同一である

次の 3 つは、代数的に符号が一致する。

$$\mathrm{OBI}_t = \frac{q^b - q^a}{q^b + q^a}, \qquad q^b + q^a > 0$$

$$\mathrm{BookSlope}_t = \frac{q^b - q^a}{h_t}, \qquad h_t > 0$$

$$\mathrm{micro}_t - m_t = \frac{(q^b - q^a)(P^a - P^b)}{2(q^b + q^a)}, \qquad P^a > P^b$$

いずれも $\mathrm{sign}(q^b - q^a)$ に等しい。仮定せず全 35,169,386 行で突き合わせた。

| 比較 | 符号が食い違った行 |
|---|---:|
| OBI vs BookSlope | **0 件** |
| OBI vs micro_dev(因数分解した式) | **0 件** |
| OBI vs micro_dev(素朴な引き算) | **187,120 件(0.53%)** |

正規化しても符号は変わらないので、OFI_z = OFI / s($s > 0$)も OFI と同じ推移行列に
なる。**つまりこの 3 つ(と OFI_z)を別々の行として報告するのは水増しである。**
表では 1 行にまとめた。

### ★素朴に書くと「ちょうど 0」が壊れる

micro_dev を定義どおりに

```
micro - mid = (P^b·q^a + P^a·q^b)/(q^b + q^a) - (P^b + P^a)/2
```

と書くと、符号が OBI と **187,120 行で食い違った**。調べたところ、
**その 100% が OBI がちょうど 0(つまり $q^b = q^a$)の行**だった。

原因は桁落ちである。この標本で mid は 1,087 前後、micro − mid は 5×10⁻² 前後。
$q^b = q^a$ のとき真値はちょうど 0 だが、1,087 級の数どうしの引き算で
10⁻¹³ 程度の丸め残差が残り、それが符号を持ってしまう。float64 の刻みは
mid 付近で 2.3×10⁻¹³ なので、桁として整合する。

分子を因数分解した $(q^b - q^a)(P^a - P^b) / (2(q^b + q^a))$ なら
$q^b - q^a$ が 0 のとき厳密に 0 になり、**不一致は 0 件**になった。

この標本では micro_dev のちょうど 0 が全体の 1.35% あるので、素朴な式を使うと
その全部が誤って ± に分類される。中立の状態を測る分析では見過ごせない。
[MicroPrice レポート](mu_microprice_report.md)は帯を使っており符号の細部に
依存しないが、符号そのものを数える本レポートでは効いた。

## 6. 機械的な持続ではないか

OBI の +25.6pp を見て真っ先に疑うべきは、**そもそも値が動いていないから符号が
続いているだけではないか**という可能性である。測った。

| | 件数 | 割合 |
|---|---:|---:|
| 隣接イベント組 | 35,169,288 | 100% |
| 両側の数量が全く同じ | 1,111,811 | 3.16% |
| 両側の価格が全く同じ(数量だけの更新) | 13,575,478 | 38.60% |
| **OBI の値が変化した組** | **34,053,524** | **96.83%** |

OBI がまったく動かない組は 3.16% しかない。そこで **OBI の値が実際に変化した組
だけに限って**同じ計算をした。

| 標本 | P(正\|正) | 無条件 P(正) | 超過 |
|---|---:|---:|---:|
| 全組 | 74.91% | 49.22% | +25.69pp |
| **OBI が動いた組のみ** | **74.12%** | 49.27% | **+24.84pp** |

超過は +25.69 から +24.84 へ 0.85pp 下がるだけである。機械的な寄与は全体の
**約 3%** にとどまり、残りは値が動いてもなお符号が同じ側に留まることによる。
持続性は本物である。

なお最良気配のイベントの 38.6% は価格が動かず数量だけが変わる更新であった。
板の更新は価格の更新より数量の更新のほうがずっと多い。

## 7. ばらつきと多重比較

### 日ごとに見る —— 中央値だけでは足りない

k=1 の持続性(帰無対照で補正する前)を日ごとに出した。

| 特徴量 | 正の日 | 最小 | 中央 | 最大 |
|---|---:|---:|---:|---:|
| OBI | **98 / 98** | +18.46 | +26.02 | +33.95 |
| テイカーの向き | **98 / 98** | +8.61 | +15.15 | +26.08 |
| OFI | **98 / 98** | +3.14 | +9.38 | +18.09 |
| mid のリターン | 97 / 98 | **−0.14** | +6.32 | +15.52 |
| Δスプレッド幅 | 9 / 98 | −10.51 | −4.60 | +3.49 |
| Δ最良気配数量 | **0 / 98** | −13.83 | −8.27 | −4.68 |

上位 3 つは 98 日すべてで正、Δ最良気配数量は 98 日すべてで負である。数日の外れ値が
結論を作っているのではない。mid のリターンだけ 1 日(最小 −0.14pp)がわずかに
負に振れているが、無視できる大きさである。

### 多重比較

6 特徴量 × 5 ラグ = **30 通り**を報告している。日ブロックブートストラップ
(4,000 反復)で 95% 区間と Bonferroni 相当の区間($\alpha = 0.05/30$)を出した。

**30 通りのうち 29 通りが Bonferroni 補正後も 0 を跨がない。** 跨ぐのは 1 つだけ。

| 特徴量 | k | 持続性 | 95% 区間 | Bonferroni 区間 |
|---|---:|---:|---|---|
| Δスプレッド幅 | 2 | −0.32 | [−0.59, −0.05] | **[−0.71, +0.12]** |

つまり Δスプレッド幅は k=1 で明確に負、**k=2 で 0 と区別できず**、k=3 以降で正、
という向きの入れ替わりを示している。「k=2 で 0 と区別できない」は「効果が無い」
ではなく、検出できていないという意味である。

日ブロックブートストラップを使ったのは、隣接イベントが強く相関していて二項の
信頼区間が使えないためである(1 日を 1 ブロックとして 98 個から復元抽出する)。

## 8. 既存レポートとの照合

### テイカーの向き

[攻撃的な売買の向きの推移確率行列](mu_sign_chain_report.md)は 1 次の推移確率を
「買い → 次も買い **69.04%**、n = 3,379,398」と報告している。本レポートの表は
**69.00%** である。

食い違いの原因を特定した。あちらは fills のある **99 日**(8 月 10 日を含む)、
こちらは BBO のある **98 日**に限っている。同じ計算を 99 日でやり直すと
69.04%(n = 3,379,398)で**桁まで一致**した。98 日に限ると 69.00%
(n = 3,334,357)になる。8 月 10 日は BBO が無い日であり、
[データ保有状況](mu_inventory_report.md)が記録している欠損日と同じである。

### OBI のちょうど 0

本レポートの 1.35%(473,905 / 35,169,288)は
[OBI と OFI レポート](mu_obi_ofi_report.md)の「ちょうど 0 は実測で OBI の 1.35%」と
一致する。

## 9. まとめ

1. 板の残高の偏り(OBI = BookSlope = micro_dev)が最も持続し、k=1 で **+25.6pp**、
   k=5 でも **+10.3pp** 残る
2. 残高は流量(OFI)の **2.6 倍**持続する。水準と差分の違いが数字に出ている
3. Δスプレッド幅と Δ最良気配数量は k=1 で**負**、つまり直後に跳ね返る
4. 3 つの特徴量は符号として**厳密に同一**であり、別々に数えるのは水増しである
5. micro_dev を素朴な引き算で書くと、**ちょうど 0 の行 187,120 件すべて**で符号が
   壊れる。因数分解した式を使うこと
6. 帰無対照は 0 に潰れ切らない。補正しないと **2 つのセルで向きを取り違える**
7. 30 通り中 **29 通り**が Bonferroni 補正後も 0 を跨がない
8. ★これは x 自身の自己相関であって、**将来価格の予測力ではない**
