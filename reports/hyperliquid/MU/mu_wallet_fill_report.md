# xyz:MU 口座ごとの約定のされ方 11 指標 — 誰の指値が、どう約定しているか

## 1. 結論

| | 指標 | 口座の中央値 |
|---|---|---:|
| ① | **fill rate**(本数) | **0.99%** |
| ② | **fill probability**(数量加重) | 0.74% |
| ③ | **fill-to-order ratio**(全量約定のみ) | 0.74% |
| ④ | **fill-to-cancel ratio** | 0.0100 |
| ⑤ | **maker execution share** | 0.01%(上位 1 者 **6.1%**) |
| ⑥ | **volume executed / quoted** | 0.57% |
| ⑦ | **average time to fill** | **10.2 秒**(口座内中央値の中央は 1.36 秒) |
| ⑧ | **partial-fill frequency** | **12.1%** |
| ⑨ | **fill size** | **1.57 契約** |
| ⑩ | **queue-position-at-fill** | **0 契約**(先頭で約定した割合の中央値 **87.6%**) |
| ⑪ | **adverse selection after fill**(10 秒) | **+1.36 bp**(正 = メイカーに不利) |

読みどころは 4 つある。

### (1) ★ ①②③⑥ は独立な 4 つの指標ではない

指定された 11 指標のうち 4 つは「約定の割合」で、分子と分母の取り方が違うだけである。
口座間の順位相関を実測すると:

| | fill rate | fill prob | fill-to-order | vol exec/quoted |
|---|---:|---:|---:|---:|
| **fill rate** | +1.00 | +0.96 | **+0.99** | +0.96 |
| **fill prob** | +0.96 | +1.00 | +0.95 | **+0.99** |
| **fill-to-order** | +0.99 | +0.95 | +1.00 | +0.96 |
| **vol exec/quoted** | +0.96 | +0.99 | +0.96 | +1.00 |

**すべて +0.95 以上**である。口座の順位づけとしては 1 個の量とみてよい。
違いが出るのは**水準**のほうで、同じ口座でも定義によって 0.99% と 0.57% の差がつく。
4 つの関係は次のとおり:

- ① → ③ は「1 枚でも約定」から「全量約定」へ条件を厳しくする。
  中央値で 0.99% → 0.74% になる
- ② → ⑥ は「約定した注文を丸ごと数える」から「約定した枚数だけ数える」へ。
  比の中央値 **0.897** が **約定した注文が平均してどれだけ埋まったか**にあたる

**独立な発見が 4 つあるわけではない**、というのがこの節の結論である。

### (2) ほとんどの約定は「前に誰もいない」状態で起きている

⑩ **queue-position-at-fill の中央値は、どの口座でも 0 契約**だった。
約定した瞬間に自分より前に並んでいた注文が無い、という意味である。
口座ごとに「先頭で約定した割合」を出すと**中央値 87.6%**、
分布は 80〜100% に固まる(図 ⑤)。

板が薄いためで、この市場では**キュー位置は約定の説明変数としてほとんど働かない**。
置いた瞬間の「前にいる数量」も 85.3%(初日実測)がゼロである。
キュー位置で約定確率を語れる市場ではない。

### (3) ★ メイカーは約定直後に系統的に負けている — 帰無対照つき

⑪ adverse selection は、約定価格ではなく**約定時刻の mid**を起点に

```math
\mathrm{adverse} = \sigma \cdot \frac{\mathrm{mid}(t+\Delta) - \mathrm{mid}(t)}{\mathrm{mid}(t)} \times 10^4,
\qquad \sigma = \begin{cases} -1 & \text{買い方(bid)で約定} \\ +1 & \text{売り方(ask)で約定} \end{cases}
```

と定義した(正 = メイカーに不利な向きへ動いた)。

| | 10 秒後 |
|---|---:|
| 実測(口座の中央値) | **+1.356 bp** |
| 実測が正(不利)だった口座 | **90.3%** |
| **帰無対照**(約定時刻を +1 時間ずらす) | **+0.009 bp** |
| 対照が正だった口座 | 53.8%(**偶然どおり**) |
| 実測 > 対照 だった口座 | **87.9%**(Wilcoxon $`p = 6.1 \times 10^{-47}`$、n=381) |

**ずらすと消える。**したがってこれは相場の傾きや日内の形ではなく、
**約定した瞬間に固有**の逆選択である。

大きさの意味づけ: 往復スプレッドの中央値は **1.245 bp**
([OBI と OFI のレポート](mu_obi_ofi_report.md) の実測)である。
**逆選択が往復スプレッドを超える口座が 53.8%** ある。
スプレッドを取り切っても 10 秒後には負けている口座が半分ある、ということになる。

### (4) ★ 大口ほど逆選択が小さい

| | 逆選択(10 秒、中央値) |
|---|---:|
| メイカー約定シェア上位 20 口座 | **+0.523 bp** |
| それ以外(361 口座) | **+1.405 bp** |

maker execution share と逆選択の順位相関は
**$`\rho = -0.462`$**($`p = 1.7 \times 10^{-21}`$、n=381)で、
**大きく約定している口座ほど不利を受けにくい**。
約定量で重みづけた平均は **+0.700 bp** で、単純中央値 +1.356 bp の約半分になる。

図 ⑥ のとおり上位 20 者のうち **4 者は負(有利)** で、逆選択を避けきっている。
一方、上位でも +1.9 bp 前後を払っている口座がある。**規模だけでは決まらない。**

## 2. 定義

母集団は**板に留まる指値**である。

| 外したもの | 理由 |
|---|---|
| トリガー注文(`is_trigger`) | 発火するまで板に載らない |
| テイカー(`Ioc` / `FrontendMarket` / `LiquidationMarket`) | 板に留まらない。`Alo` と `Gtc` だけを見る |
| **`reduce_only`** | 下記 ★ |
| bbo の壊れた行・クロスした板 | `clean_bbo` を通す |

### 11 指標の分子と分母

| # | 指標 | 分子 | 分母 |
|---|---|---|---|
| ① | fill rate | 1 枚でも約定した注文の**本数** | 置いた**本数** |
| ② | fill probability | 1 枚でも約定した注文の**当初数量** | 置いた**当初数量** |
| ③ | fill-to-order ratio | **全量約定**した本数 | 置いた本数 |
| ④ | fill-to-cancel ratio | 約定した本数 | **1 枚も約定せず**取り消した本数 |
| ⑤ | maker execution share | その口座の約定数量 | 市場全体の約定数量 |
| ⑥ | volume executed / quoted | 実際に約定した**枚数** | 置いた当初数量 |
| ⑦ | average time to fill | Σ(最初の約定時刻 − 発注時刻) | 約定した本数 |
| ⑧ | partial-fill frequency | 約定を含むが**全量に至らず取り消した**本数 | 約定した本数 |
| ⑨ | fill size | 約定数量 | 約定イベント数 |
| ⑩ | queue-position-at-fill | \- | 約定した瞬間に自分より前にいた生存注文の数量(FIFO) |
| ⑪ | adverse selection after fill | \- | §1(3) の式。Δ = 1 / 10 / 60 秒 |

⑩ について: **FIFO なので置いた瞬間はどの注文も最後尾**である。
したがって「置いた瞬間に前にいる数量」はその価格水準の現在の合計そのもので、
「後ろにいる数量」は定義上 0 にしかならない。意味があるのは
**約定した瞬間**に測った値のほうで、本レポートの ⑩ はそちらである。

## 3. ★ 検証 — 約定量の数え方で 3 割変わる

**`status == "filled"` のイベントだけを数えると約定量を 3 割取りこぼす。**
`filled` イベントを持たないまま約定している注文があり、その分は
**取消イベントの残量**にしか現れない。2026-05-04 の実測:

| 数え方 | 約定量(契約) | node_fills 比 |
|---|---:|---:|
| `filled` イベントだけ | 48,903 | 56.7% |
| **+ 取消イベントの残量も使う(採用)** | **81,617** | **94.7%** |
| + `reduce_only` も含める | 157,663 | **183%**(過大) |
| node_fills のメイカー側(真値) | 86,187 | 100% |

`reduce_only` を含めると **183%** まで膨らむ。取引所がポジション減少に合わせて
数量を自動で縮めるため、残量が減っても約定とは限らないからである。
**この過大計上が、reduce_only を外す判断の裏づけになっている。**

全期間で照合すると、採用した数え方の到達率は **99.0%**
(L1 由来 2,317.6 万契約 / node_fills 2,340.9 万契約)である。

> なお [指値注文の生存率のレポート](mu_hazard_report.md) は最終約定率を **0.915%** と
> しているが、あちらは `filled` イベントだけを終端として数えている。
> 本レポートの ① が **1.393%**(市場全体)と高いのは、上記の取りこぼしを
> 拾っているためで、矛盾ではない。**数え方が違う。**

### そのほかの検算

| 検算 | 結果 |

| 終端の排他性 | 置いた 549,920,651 = 全量 5,029,517 + 部分後取消 2,625,338 + 素の取消 542,251,098 + 未終端 14,698(**0.0027%**) |
| 集計と明細の一致 | Σv_fill と明細の Σfill_sz の差 **0** / 件数も一致(765.9 万) |
| キュー走査の打ち切り | **0 件**(上限 4,096 本に達したキューは無い) |

| adverse が計算できなかった約定 | 10 件 / 765.9 万件。**polars の `mean()` は NaN を伝播する**ので、この 10 件だけで上位 2 口座の平均が NaN に化けていた(修正済み) |

## 4. 対象の選び方

指標は割合なので分母が小さい口座では暴れる。**結果を見る前に**
「置いた本数が 10,000 本以上」という活動量だけの閾値で選んだ
(約定した口座を選ぶと生存バイアスになる)。

| | 値 |
|---|---:|
| 全口座 | 14,877 |
| 閾値を満たす口座 | **395** |
| 覆う注文 | 5 億 4,834 万本(**99.7%**) |
| 覆うメイカー約定量 | **82.3%** |

約定量の 17.7% は閾値未満の口座が出しているので、**⑤ の合計は 1 にならない**。

## 5. 市場全体の姿

| | 本数ベース | 数量ベース |
|---|---:|---:|
| 約定率 | **1.393%** | **0.276%** |

**置いた数量の 99.7% は約定せずに消える。**
本数と数量で 5 倍の差がつくのは、大きい注文ほど約定しにくいためである。

集中度は **HHI 0.019**、上位 1 者 6.1% / 上位 5 者 23.1% と、
**メイカー約定はさほど集中していない**。
これは [ウォレットの MM らしさのレポート](mu_wallet_mm_report.md) が
「板を厚く出しているのは少数」としたのと対照的で、
**板を出す量の集中と、約定を取る量の集中は別物**である。

## 6. 限界

- **同一主体が複数口座を持つ場合は分離できない。** ⑤ の集中度はその分だけ
  過小に出る。本文は順位と集計だけで書き、個々の口座を名指ししていない。
  数値データ `wfmetrics_xyz_MU.csv` にはオンチェーンのアドレスを載せている
  (`wallet_mm_xyz_MU.csv` と揃えて、レポート間で口座を突き合わせられるようにするため)。
  ただし [見せかけの板のレポート](mu_manipulation_report.md) のように
  **特定の口座の意図を疑う分析では内部連番だけを使う**。本レポートは
  執行の記述統計であり、どの口座についても意図を推定していない。
- **adverse selection は mid の変化であって損益ではない。** 手数料・在庫の
  持ち越し・その後の反対売買を含んでいない。「約定直後に不利へ動く」ことは
  示せるが、その口座が赤字だとは言っていない。
- **⑦ average time to fill は約定した注文だけの平均**である。約定しなかった
  注文(98.6%)は含まれないので、「置いたら 10 秒で約定する」とは読めない。
  打ち切りを扱った生存分析は [ハザードのレポート](mu_hazard_report.md) にある。
- **node_fills との差 1.0%** は、窓の外で終端した注文とトリガー由来の約定と
  考えられるが、内訳までは詰めていない。
- **1 銘柄・98 日**の結果である。他の 5 銘柄へは当てていない。
- ⑩ のキュー位置は**同一価格水準の FIFO**を仮定している。取引所が
  価格改善やバッチで順序を変える場合は一致しない。
