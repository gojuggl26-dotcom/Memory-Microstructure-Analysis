## 1. 結論

**13 種すべてを 6 つの地平・2 つの目的変数に当てた 156 セルのうち、
4 段の検査を全部通ったのは 1 セルだけだった。**

| 検査 | 残ったセル |
|---|---|
| 全体 | 156 |
| ① Bonferroni($`p \lt  3.2 \times 10^{-4}`$)を通過 | **49** |
| ①+② 帰無対照が閾値未満 | 46 |
| ①+②+③ 前向き > 後ろ向き | **3** |
| ①+②+③+④ 活動量を統制しても半分以上残り符号も同じ | **1** |

読みどころは 4 つある。

**(1) 向きにはまったく効かない。効くのはボラティリティだけである。**
Bonferroni を通った 49 セルは**全部が $`|r|`$(ボラティリティ)**で、
**向き $`r`$ は 0 セル**だった。向きへの順位相関は最大でも
$`|\rho| = 0.008`$ で、往復スプレッド 1.245 bp に対して論じる意味がない。
これはエントロピーが**符号を持たない散らばりの指標**である以上、
期待どおりの姿である。

**(2) 大半は「注文が多いと荒れる」の言い換えだった。**
最も強く見えた $`H_\mathrm{side}`$ は素の $`\rho = 0.168`$ だが、板の本数と
イベント数を統制すると **0.013 まで落ちる(8% しか残らない)**。
$`H_\mathrm{action}`$ も 0.151 → −0.012 で**符号まで反転**する。
エントロピーは母集団が大きいほど機械的に上がるので、統制を外すと
活動量そのものを掴んでしまう。

**(3) さらに大半は「前触れ」ではなく「後始末」だった。**
同じ手順を過去のリターンに当てると、13 種中 10 種で**後ろ向きのほうが強い**。
$`\bar{H}_\mathrm{row}`$(transition)は前向き −0.167 に対し後ろ向き −0.401 で、
比は 0.42 にすぎない。値動きがあったから板の記号列が乱れるのであって、
逆ではない。

**(4) 唯一生き残ったのは Δエントロピー(1 秒)である。**

| | 値 |
|---|---|
| セル | $`\Delta H_\mathrm{depth}`$ → 将来 1 秒の $`|r|`$ |
| 日ごとの $`\rho`$ の中央値 | **−0.0526** |
| 符号検定 | **98 日中 0 日が正**($`z = -9.90`$、$`p = 4.2 \times 10^{-23}`$) |
| 帰無対照 | $`z = -2.42`$(閾値 3.60 未満・素通り) |
| 後ろ向き | −0.0464(前向きのほうが **1.13 倍**大きい) |
| 活動量を統制 | **−0.0376**(71% が残り、符号も同じ) |

向きは負である。つまり **1 秒の間に板の数量エントロピーが下がった(流動性が
少数の価格水準へ集まった)直後は、次の 1 秒が荒れやすい**。
ただし効果量は $`\rho = -0.05`$ と小さく、しかも次項のとおり
**この順位相関は関係の形を取り違えている**。

### ★ 関係は単調ではなく U 字だった

$`\Delta H_\mathrm{depth}`$ を十分位に切って次の 1 秒の $`|r|`$ の中央値を見ると、
**両端で荒れ、中央で凪ぐ**。順位相関はこの U 字の左右差しか拾えない。

| 十分位 | 1(最も下がった) | 3 | 5–6(ほぼ不変) | 8 | 10(最も上がった) |
|---|---:|---:|---:|---:|---:|
| $`\Delta H_\mathrm{depth}`$ 中央 | −0.086 | −0.013 | 0.000 | +0.015 | +0.083 |
| 次の 1 秒の $`|r|`$ 中央値 | **0.895 bp** | 0.160 bp | **0.000 bp** | 0.151 bp | **0.566 bp** |

第 1 十分位と第 10 十分位の比は **1.58 倍**、帰無対照では 0.29 倍で、
非対称そのものは本物である。しかし**中央と両端の差のほうがはるかに大きい**。

そこで**変化の大きさ** $`|\Delta H_\mathrm{depth}|`$ で測り直すと、
$`\rho`$ は 1 秒地平で **0.264** と 5 倍になり、**98 日すべてで正**、
全 6 地平で $`z = 9.90`$ になる。ところがこの版は残りの 2 つの検査に落ちる。

| 地平 | 前向き $`\rho`$ | 後ろ向き $`\rho`$ | 統制後 $`\rho`$ |
|---|---:|---:|---:|
| 1s | 0.264 | **0.425** | **0.040** |
| 10s | 0.195 | **0.304** | **0.040** |
| 60s | 0.159 | **0.217** | **0.032** |

**後ろ向きが一貫して大きく、統制すると 85% が消える。**
$`|\Delta H_\mathrm{depth}|`$ は「板がかき回された」ことの記録であって、
その先を教えるものではない。

> **この U 字は、順位相関だけを見ていたら気づけなかった。**
> 十分位表を作ったのは数字を出したあとで、しかもそれで結論が変わった。
> $`|\Delta H|`$ の追試は探索の一部なので、156 セルの Bonferroni とは
> 別枠(6 セル)として数えている。

## 2. 定義

エントロピーは確率分布 $`p`$ の散らばりを測る量で

```math
H(p) = -\sum_i p_i \log_2 p_i
```

と定義する。単位はビット。1 点に集中していれば $`H = 0`$、$`k`$ 個に均等なら
$`H = \log_2 k`$ で最大になる。**逆に読むと $`2^H`$ は「実効的な個数」**で、
たとえば $`H = 5`$ ビットなら「均等に 32 個へ散らばっているのと同じ」を意味する。
本レポートでは分かりやすさのためこの $`2^H`$ をよく使う。

### 板のエントロピー(6 種)

母集団は**その瞬間に板に載っている指値注文**である。

| 記号 | 名前 | 確率 $`p`$ の取り方 |
|---|---|---|
| $`H_\mathrm{depth}`$ | depth entropy | 価格水準 $`i`$ ごとの**数量** $`p_i = v_i / \sum v`$ |
| $`H_\mathrm{size}`$ | order-size entropy | 注文数量の $`\log_2`$ 階級 $`b`$ ごとの**本数** $`p_b = n_b / N`$ |
| $`H_\mathrm{plevel}`$ | price-level entropy | 価格水準 $`i`$ ごとの**本数** $`p_i = n_i / N`$ |
| $`H_\mathrm{wallet}`$ | wallet entropy | 口座 $`w`$ ごとの**数量** $`p_w = v_w / \sum v`$ |
| $`H_\mathrm{age}`$ | order-age entropy | 滞留時間の対数階級ごとの**本数** |
| $`H_\mathrm{queue}`$ | queue entropy | **最良気配の待ち行列内**で、注文 $`k`$ の数量シェア $`p_k = s_k / \sum s`$ |

$`H_\mathrm{depth}`$ と $`H_\mathrm{plevel}`$ は同じ価格水準を見ているが、前者は
**数量で**、後者は**本数で**重みづける。両者が離れるとき、板は「本数は広く
散っているのに数量は少数の水準に固まっている」状態にある。

$`H_\mathrm{queue}`$ は両側それぞれの最良気配について算出し、**数量で重みづけた
平均**を取る。片側の最良に注文が 1 本しかなければその側は 0 とする。

### イベントのエントロピー(3 種)

母集団は**直前 1 秒に起きたイベント**である。

| 記号 | 名前 | 分類 |
|---|---|---|
| $`H_\mathrm{action}`$ | NEW / REMOVE / UPDATE entropy | 3 値。NEW = 板に載った、REMOVE = 消えた、UPDATE = 部分約定で数量だけ減った |
| $`H_\mathrm{side}`$ | side entropy | 2 値(bid / ask)。上限 1 ビット |
| $`H_\mathrm{dir}`$ | event-direction entropy | 2 値。**上向き** = bid に置く or ask を消す、**下向き** = ask に置く or bid を消す |

$`H_\mathrm{dir}`$ は「板を押し上げる働きと押し下げる働きが、どれだけ拮抗して
いるか」を測る。1 ビットなら完全に拮抗、0 なら一方通行である。

### 動的なエントロピー(4 種)

| 記号 | 名前 | 定義 |
|---|---|---|
| $`\Delta H`$ | entropy change | $`H_\mathrm{depth}(T) - H_\mathrm{depth}(T-1 \mathrm{s})`$ |
| $`h_2`$ | entropy rate | $`H_2 / 2`$。$`H_2`$ は連続する 2 記号の同時エントロピー |
| $`H(X_t \mid X_{t-1})`$ | conditional entropy | $`H_2 - H_1`$ |
| $`\bar{H}_\mathrm{row}`$ | transition entropy | 観測された行 $`i`$ について $`H(\text{次} \mid \text{現在}=i)`$ を**出現頻度で重みづけせず**平均 |

記号は**動作 × 側**の 6 値、窓は直前 10 秒とする。

> **★この 3 つは独立ではない。** $`h_2`$・$`H(X_t \mid X_{t-1})`$・$`\bar{H}_\mathrm{row}`$ は
> いずれも同じ 2 記号ブロック分布から作るので、定義上つよく関係する。
> 別物として並べると「13 個の独立な発見がある」と誤読されるため、
> **実測した相関を §5 に出す**。$`\bar{H}_\mathrm{row}`$ だけは行を占有確率で
> 重みづけないので $`H(X_t \mid X_{t-1})`$ とは一致しない
> (「よく出る状態」ではなく「典型的な状態」の出口の読みにくさを測る)。

## 3. 母集団から外したもの

| 外したもの | 理由 |
|---|---|
| トリガー注文(`is_trigger`) | 発火するまで板に載らない |
| テイカー(`Ioc` / `FrontendMarket` / `LiquidationMarket`) | 板に留まらない。`Alo` と `Gtc` だけを見る |
| **mid から ±100bp より外の指値** | 下記 ★ |
| クロスした板(`best_ask` ≤ `best_bid`)と bbo の壊れた行 | 少数の異常行が係数を大きく動かした前例がある(`clean_bbo`) |
| 欠測時間帯(6 日・計 7 時間) | 板が凍って見え、エントロピーが「一定」に化ける |
| 帯の中の注文が 3 本未満の格子 | エントロピーが定義できない、または常に 0 |

**★ 遠方に駐機している注文を入れると板の統計がそれだけで決まる。**
発注時の mid からの距離は p90 が 64.5bp なのに **p95 で 999bp へ跳ぶ**。
1000bp 付近に明らかに別の群があり、これらは長期間動かない。
帯を ±100bp に切ると発注の **90.8%** を覆いつつこの群を落とせる。

## 4. 時間契約(先読みをしていないこと)

格子時刻 $`T`$ について、

- **板の 6 種** … $`ts \lt  T`$ のイベントだけを適用した板の状態。同一 ns に自分自身が
  含まれうるので**厳密に** $`\lt `$ で切る
- **イベントの 3 種** … $`[T-1 \mathrm{s},\ T)`$ に起きたイベント
- **動的の 4 種** … $`\Delta H`$ は $`T`$ と $`T-1 \mathrm{s}`$ の板、残りは $`[T-10 \mathrm{s},\ T)`$
- **目的変数** … $`[T,\ T+h)`$ の mid の対数リターン($`h`$ = 1, 2, 5, 10, 30, 60 秒)

bbo の asof は backward のみ(「厳密に $`T`$ 未満の最後の行」)。
説明変数が確定する時刻は、いずれも目的変数の期間の開始時刻以前である。
「予測」と「同時点の関係」の書き分けは [予測の定義](../../predicting_definition.md) に従う。

### 重ならない標本

格子は 1 秒なので、地平 $`h`$ の窓 $`[T, T+h)`$ は $`h`$ 個の格子で重なる。
重なった標本のまま相関を測ると自由度が $`h`$ 倍に水増しされるので、
**stride = $`h`$ で間引く**。

### 判定の手順

1. **効果量** — 重ならない標本での Spearman 順位相関 $`\rho`$
2. **頑健性** — **日ごとに** $`\rho`$ を出し、その符号を 98 日で**符号検定**する。
   1 秒格子の隣接点は強く相関するので、プールした標本数から出した $`z`$ は使わない
3. **帰無対照** — $`x`$ を日の中で 12 時間**巡回シフト**して同じ手順を通す。
   ずらしても残る相関は、因果ではなく日内の形が作っている
4. **統制** — 板の本数 $`n_\mathrm{ord}`$ とイベント数 $`n_\mathrm{ev}`$ を順位で回した後の
   **偏順位相関**。エントロピーは母集団が大きいほど機械的に上がるので、
   これを外さないと「注文が多い時間は荒れる」の言い換えを掴む
5. **同時性の検査** — 同じ手順を**過去のリターン** $`[T-h,\ T)`$ にも回す。
   前向きより後ろ向きが大きければ、それは値動きの**後始末**であって前触れではない

**多重比較**: 13 特徴量 × 6 地平 × 2 目的変数 = **156 セル**を全件報告する。
Bonferroni 閾値は $`0.05 / 156 = 3.2 \times 10^{-4}`$(符号検定の $`|z|`$ で 3.60)。

## 5. 13 種は何を捉えているか

### 実効的な個数で読む

| 何の散らばりか | 中央値(ビット) | 実効的な個数 $`2^H`$ |
|---|---:|---:|
| 価格水準(**本数**) | 8.44 | **348.0** |
| 価格水準(**数量**) | 6.45 | **87.6** |
| 口座(数量) | 4.44 | 21.7 |
| 注文数量の階級 | 3.28 | 9.7 |
| 滞留時間の階級 | 2.41 | 5.3 |
| 最良の待ち行列 | 0.57 | 1.5 |

本数で数えると板は 348 水準に広がっているのに、**数量で見ると実効 87.6 水準**しかない。
数量は少数の価格水準に固まっている。口座は実効 21.7 者で、板の 1,563 本(最大の日)を
出しているのが実質 20 者程度であることを意味する。

**最良気配の待ち行列は実効 1.5 本しかない。** 実際、**35.9% の時刻で最良に注文が
1 本しか無い**。queue entropy は「待ち行列の分かれ方」というより
「最良に 2 本以上あるか」の指標に近く、この市場では情報量が乏しい。

### 冗長性 — 13 個は独立ではない

| 組 | 順位相関 |
|---|---:|
| entropy rate ↔ conditional | **+0.96** |
| conditional ↔ transition | **+0.98** |
| entropy rate ↔ transition | **+0.93** |
| depth ↔ price-level | +0.64 |
| **depth ↔ 板の本数 $`n_\mathrm{ord}`$** | **+0.76** |

動的な 3 種は同じ 2 記号ブロック分布から作るので、実質**1 個の量**である。
13 個を並べて数えるのは水増しになる。

$`H_\mathrm{depth}`$ と板の本数の相関が +0.76 ある点も重要で、
これが §1(2) の「統制すると消える」の正体である。

### 水準が動く

図 1 ⑤ のとおり、日ごとの平均は**期間を通じて上がり続ける**
($`H_\mathrm{plevel}`$ は 7.0 → 9.1)。板が厚くなっているためで、
エントロピーの**水準**を期間をまたいで比べてはいけない。
本レポートの判定を日ごとの順位相関にしてあるのは、この理由でもある。

### 帰無対照が発火したセル

156 セル中 **9 セル**で、時間を 12 時間ずらした対照が Bonferroni 閾値を越えた。
内訳は **order-size の全 6 地平**と **entropy change の 3 地平**である。

order-size は実測の $`|z|`$(最大 2.2)が**対照の $`|z|`$(最大 4.2)より小さい**。
つまり order-size に見えていた関係は**丸ごと日内の形が作ったもの**で、
実体はない。entropy change は実測 −9.9 に対し対照 −4.8 で実測がはるかに強いが、
日内の形による寄与が混じっていることは記録しておく
(唯一生き残った 1 秒地平では対照は −2.42 で閾値未満)。

## 7. 費用と比べる

**向きに使える大きさではない。** 向きへの順位相関は 156 セル中の最大でも
$`|\rho| = 0.008`$ である。往復スプレッドの中央値 1.245 bp
([OBI と OFI のレポート](mu_obi_ofi_report.md) の実測)を前提にすると、
この相関から取り出せる期待値は費用の桁に届かない。

**ボラティリティ側には効くが、この市場では直接には換金できない。**
$`|\Delta H_\mathrm{depth}|`$ の第 1 十分位と第 10 十分位で次の 1 秒の $`|r|`$ は
1.58 倍違う。ボラティリティそのものを売買する手段(オプション等)が
この銘柄には無いため、使うとすれば**メイカーとして板に出すかどうかの
出し引き**になる。ただし §1(4) のとおり前向きの関係は後ろ向きより弱く、
実装するなら「荒れた直後に引く」という**後追いの規則**にしかならない。

## 8. 限界

- **単調性を仮定していない検証は十分位表だけである。** 156 セルは順位相関で
  測っており、U 字のような非単調な関係は取り逃がす。entropy change で
  それが起きていたので、他の 12 種にも同種の見落としがある可能性がある。
- **queue entropy はこの市場では情報量が乏しい**(35.9% の時刻で最良が 1 本)。
  板が厚い銘柄では別の姿になりうる。
- **帯 ±100bp は結果を見る前に決めた**が、感度は測っていない。
  帯を変えると板の 6 種はすべて動く。
- **口座は内部連番で扱っており、同一主体が複数口座を持つ場合は分離できない**。
  wallet entropy はその分だけ過大に出る。
- **分割実行の継ぎ目**(49 日目)で板の持ち越しが 5 日の温めで足りているかは、
  継ぎ目の跳びが他の日境界の分布の内側(19〜67 パーセンタイル)に収まることで
  確認した。厳密な再計算による突合はしていない。
- **1 銘柄・98 日**の結果である。他の 5 銘柄へは当てていない。


## 検算

エントロピーの計算そのものは手計算できる既知の値と突き合わせてある
(`build_entropy.py --selftest`)。

| 検査 | 期待値 |
|---|---|
| 1 点に集中 | 0 ビット |
| 2 / 4 / 8 個に均等 | 1 / 2 / 3 ビット |
| 偏り [3, 1] | 0.8112781 ビット |
| ゼロ要素を含む | 無視される |
| 総和を 100 倍 | 変わらない(尺度不変) |
| 総和 0 | 定義できない(nan) |

さらに、算出した 13 種すべてが**理論上限 $`\log_2 k`$ を超えていない**ことを
全期間で確認した(超えていれば数え方が壊れている)。
