# 「予測力」の算出方法(全レポート共通)

各レポートに出てくる「予測力 / 相関」がどう計算されているかを一箇所にまとめる。
2026-08-14 時点で、全レポートがこの方式に統一されている
(`obi_report.md` §4 だけプール値だったものを日次中央値へ訂正済み)。

---

## 1. 目的変数 y — 中値の対数リターン(bp)

### 窓ベースの指標(`oi_grid` / `cancel_grid` / `flow_grid`)

指標 x は窓 $[T,\; T+\Delta)$ を集計した値なので、T+Δ にならないと確定しない。
したがって評価に使うリターンは窓が閉じた後から始める。

```
y = ( log mid(T + 2Δ) − log mid(T + Δ) ) × 10⁴      [bp]
```

先読みは構造的に起こりえない(x が判る時点 = y の起点)。

参考値として「同窓の相関」も出しているレポートがあるが、
これは窓の中で同時に起きた値動きとの相関であり、因果ではなく機械的な同時性である。
判断には次窓の相関だけを使う。

### イベントベースの指標(`microprice` / `obi` / `features`)

x はイベント時刻 t の板の状態で、t の時点で確定している。

```
y = ( mid(t + h) − mid(t) ) / mid(t) × 10⁴          [bp]
h ∈ { 次イベント, 100ms, 1s, 10s, … }
```

先読みは無いが、t の瞬間に約定できる前提の数字である点は割り引いて読むこと。

### `mid(u)` の定義

`u` 以前の直近値(階段関数)。`np.searchsorted(..., side="right") − 1` または
polars の `join_asof(strategy="backward")` で取る。
クロス状態(`best_ask < best_bid`)は事前に除外している
(理由は `regression_report.md` §2)。

---

## 2. 統計量 — 日次のピアソン相関を 99 日ぶん取り、中央値で読む

```
各日 d について   ρ_d = corr(x, y)          … その日の全行を使う
報告するのは      median(ρ_d), IQR(ρ_d), #{d : sign(ρ_d) ≠ 期待符号}
```

プールした単一の相関・t 統計量は使わない。 理由は監査(`regression_report.md` §9):

| 監査項目 | 結果 |
|---|---|
| 日次推定の異質性 | I² = 99.7%、Cochran の Q = 35,887(df 97)。共通の母数が無い |
| プール推定のレバレッジ | 上位 5 日で 45%。少数日の回帰に化ける |
| n の大きさ | 10⁷〜10⁸。Bartlett の SE が 1×10⁻⁵ になり、どんな微小値も「有意」になる |
| 日次 β の自己相関 | ACF(1) = 0.90。iid を仮定した t は 4 倍過大 |

そこで p 値ではなく 「99 日中、何日で符号が保たれたか」 を頑健性の指標にしている。
例: `n_cancel_ask`(100ms)は 99 日中 87 日で正 → 偶然では説明しにくい。

## 3. 除外規則

| 規則 | 理由 |
|---|---|
| `is_crossed` の行を除外 | mid が板の外に出て意味を失う(全体の 0.05%、`regression_report.md` §2) |
| x または y が非有限の行を除外 | 窓に約定が無い、片側が空、などで未定義になる |
| その日の有効行が 500 未満なら、その日を集計から外す | 少数点からの相関は不安定 |
| x または y の分散が 0 なら、その日を外す | 相関が未定義。1ms 窓で 30 日が欠けるのはこれ<br>(その日は中値が 1ms の間に一度も動いていない) |
| ★極値を取るときは板再構成の境界行(`ts % 1e9 == 999999999`)も除外する<br>(2026-08-17 追加) | 全 99 日に 4,792 行(0.02%)存在し、まれに両側の気配が同時に半値へ飛ぶ。<br>平均・中央値・相関には影響しないが、最大値・最小値・レンジ・<br>日中最小 equity など極値統計は 1 行で壊れる。<br>実際 `test_capital_report.md` §4 の「10× は最悪日で清算」は<br>2 行が作った人工物だった(報告 36 §7 で撤回) |

「有効日数」を各表に併記しているのはこのため。日数が 99 未満の欄は、
上記のいずれかで日が落ちている。

> 極値統計の一般則: 平均や中央値は 0.02% の異常行に鈍感だが、
> `min` / `max` / レンジ / ドローダウン / VaR の最悪側はその 0.02% だけで決まる。
> `is_crossed` を除いたから安全、とは言えない。極値を報告するときは必ず
> その極値を作っている行を 1 行ずつ目で見ること。
