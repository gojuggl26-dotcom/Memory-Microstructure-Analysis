## この対象を他と分けて扱う理由

板ではなく**金利と担保**の市場なので、マイクロストラクチャーの指標がそのまま
は当てはまらない。ここで測るのは

- 供給金利 / 借入金利 / 利用率(utilization)の動き
- 担保の構成と、清算が起きる価格までの距離
- **レバレッジが perp 市場へどう伝播するか**(研究方針書 §8・§24-3)
